**Ethereum on Arm — это специальный образ Linux, который может превратить Raspberry Pi в узел Эфириума.**

Для использования Ethereum on Arm с целью превращения Raspberry Pi в узел Эфириума рекомендуется следующее оборудование:

- Raspberry Pi 5 с 16 ГБ оперативной памяти
- NVMe HAT для Raspberry Pi 5, чтобы подключить NVMe-диск
- NVMe SSD (M.2 2280), минимум 4 ТБ. Избегайте дисков с контроллером Phison, у которых есть известные проблемы с совместимостью.
- Карта MicroSD (минимум 16 ГБ, класс 10)
- Блок питания
- Кабель Ethernet
- Переадресация портов (дополнительную информацию см. в документации клиентов)
- Корпус с радиатором
- USB-клавиатура, монитор и кабель HDMI (micro-HDMI) (необязательно)

Ethereum on Arm также поддерживает другие платы ARM, такие как NanoPC T6, Rock 5B и Orange Pi 5 Plus. Эти платы имеют встроенную поддержку NVMe, поэтому команда Ethereum on Arm рекомендует их вместо Raspberry Pi 5, если вы покупаете новое оборудование. Подробности см. в [списке рекомендуемого оборудования](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/overview/supported-hardware.html). Остальная часть этого руководства одинакова для всех поддерживаемых плат, за исключением файла образа, который вы скачиваете.

## Зачем запускать Эфириум на ARM? {#why-run-ethereum-on-arm}

Платы ARM — это очень доступные, гибкие и компактные компьютеры. Они отлично подходят для запуска узлов Эфириума, поскольку их можно купить недорого, настроить так, чтобы все их ресурсы были сосредоточены только на узле (что делает их эффективными), они потребляют мало энергии и имеют небольшие физические размеры, поэтому могут незаметно разместиться в любом доме. Кроме того, развернуть узлы очень просто, так как карту MicroSD для Raspberry Pi можно просто прошить готовым образом, без необходимости скачивать или собирать программное обеспечение.

## Как это работает? {#how-does-it-work}

Карта памяти Raspberry Pi прошивается готовым образом. Этот образ содержит все необходимое для запуска узла Эфириума. С прошитой картой пользователю нужно только включить Raspberry Pi. Все процессы, необходимые для работы узла, запускаются автоматически. Это работает, потому что карта памяти содержит операционную систему (ОС) на базе Linux, поверх которой автоматически запускаются процессы системного уровня, превращающие устройство в узел Эфириума.

Образы Ethereum on Arm основаны на 64-битном дистрибутиве Linux, который оптимизирован для запуска узла Эфириума, и включают в себя предварительно собранные клиенты Эфириума.

**Образы берут на себя все необходимые шаги**, от настройки среды и форматирования NVMe-диска до установки программного обеспечения Эфириума.

## Примечание о клиентах исполнения и консенсуса {#note-on-execution-and-consensus-clients}

Образ Ethereum on Arm включает предварительно собранные клиенты исполнения и консенсуса в виде служб. Для работы узла Эфириума требуется, чтобы оба клиента были синхронизированы и запущены. Вам нужно только скачать и прошить образ, а затем запустить службы. В образ предварительно загружено несколько клиентов исполнения (таких как Geth, Nethermind, Besu, Erigon и Reth) и клиентов консенсуса (таких как Lighthouse, Prysm, Teku, Nimbus и Lodestar). Текущий список см. в [документации Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/running-a-node/managing-clients.html).

Вам следует выбрать по одному клиенту каждого типа для запуска — все клиенты исполнения совместимы со всеми клиентами консенсуса. В этом руководстве используются Geth и Lighthouse.

## Скачивание образа {#downloading-the-image}

Образ Ethereum on Arm — это образ типа «подключи и работай», который автоматически устанавливает и настраивает как клиент исполнения, так и клиент консенсуса, конфигурируя их для взаимодействия друг с другом и подключения к сети Эфириума. Все, что нужно сделать пользователю, — это запустить их процессы с помощью простой команды.

Скачайте последнюю версию образа для вашей платы со [страницы загрузки Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/getting-started/installation.html#image-downloads). На странице загрузки также указана контрольная сумма SHA-256 каждого образа. Проверьте скачанный файл с ее помощью:

```sh
# Из директории, содержащей скачанный образ
sha256sum ethonarm_rpi5_<version>.img.zip
# Сравните вывод с контрольной суммой на странице загрузки
```

## Прошивка MicroSD {#flashing-the-microsd}

Карту MicroSD, которая будет использоваться для Raspberry Pi, сначала следует вставить в настольный компьютер или ноутбук, чтобы ее можно было прошить. Затем следующие команды терминала прошьют скачанный образ на SD-карту:

```shell
# проверьте имя карты MicroSD
sudo fdisk -l

>> sdxxx
```

Очень важно правильно указать имя, потому что следующая команда включает `dd`, что полностью стирает существующее содержимое карты перед записью на нее образа. Чтобы продолжить, перейдите в каталог, содержащий заархивированный образ:

```shell
# распакуйте и прошейте образ
unzip ethonarm_rpi5_<version>.img.zip
sudo dd bs=1M if=ethonarm_rpi5_<version>.img of=/dev/<sdxx> conv=fdatasync status=progress
```

Теперь карта прошита, поэтому ее можно вставить в Raspberry Pi.

## Запуск узла {#start-the-node}

Вставив SD-карту в Raspberry Pi, подключите кабель Ethernet и NVMe-диск, а затем включите питание. ОС загрузится и автоматически начнет выполнять предварительно настроенные задачи, которые превращают Raspberry Pi в узел Эфириума, включая форматирование NVMe-диска и установку клиентского программного обеспечения. Вероятно, это займет 10–15 минут, и по завершении плата автоматически перезагрузится. Не прерывайте электропитание в это время.

Как только все будет установлено и настроено, войдите в устройство через SSH-соединение или используя терминал напрямую, если к плате подключены монитор и клавиатура. Используйте аккаунт `ethereum` для входа, так как он имеет разрешения, необходимые для запуска узла.

```shell
User: ethereum
Password: ethereum
```

При первом входе в систему вам будет предложено изменить пароль по умолчанию. Сделайте это, потому что в противном случае любой, кто сможет получить доступ к вашему узлу, сможет войти в систему с паролем по умолчанию. Системный брандмауэр по умолчанию отключен, поэтому, если ваш узел имеет публичный IP-адрес, ознакомьтесь с [руководством по безопасности Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/system/security.html), чтобы включить его.

Сначала запустите клиент консенсуса. Откройте порт 9000 (TCP и UDP) на вашем маршрутизаторе, чтобы Lighthouse мог находить пиры и подключаться к ним. Затем включите и запустите службу lighthouse, чтобы она также перезапускалась после перезагрузки:

```sh
sudo systemctl enable --now lighthouse-beacon
```

Проверьте клиент с помощью логов:

```sh
sudo journalctl -u lighthouse-beacon -f
```

Затем запустите клиент исполнения. Откройте порт 30303 (TCP и UDP) на вашем маршрутизаторе, чтобы Geth мог находить пиры и подключаться к ним. Затем включите и запустите службу geth:

```sh
sudo systemctl enable --now geth
```

Вы можете убедиться, что она работает, проверив логи:

```sh
sudo journalctl -u geth -f
```

Обратите внимание, что клиент консенсуса синхронизируется за несколько минут, поскольку он использует синхронизацию по контрольной точке. Клиенту исполнения потребуется больше времени — потенциально несколько часов. Оба клиента работают одновременно: клиент консенсуса сообщает клиенту исполнения, какой блок является вершиной цепи, а клиент исполнения скачивает и проверяет блоки до него.

С запущенными и синхронизированными службами Geth и Lighthouse ваш Raspberry Pi теперь является узлом Эфириума! Чаще всего взаимодействие с сетью Эфириума происходит с использованием консоли JavaScript Geth, которую можно подключить к клиенту Geth на порту 8545. Также можно отправлять команды в формате JSON-объектов с помощью инструмента запросов, такого как Curl. Подробнее см. в [документации Geth](https://geth.ethereum.org/).

Образ также включает панель управления Grafana, которую более продвинутые пользователи могут использовать для мониторинга состояния своего узла, перейдя по адресу `ipaddress:3000` в браузере.

## Валидаторы {#validators}

К клиенту консенсуса также можно дополнительно добавить валидатор. Программное обеспечение валидатора позволяет вашему узлу активно участвовать в консенсусе и обеспечивает сети криптоэкономическую безопасность. За эту работу вы получаете вознаграждение в ETH. Чтобы запустить валидатор, у вас сначала должно быть 32 ETH, которые необходимо внести в депозитный контракт. Депозит можно сделать, следуя пошаговому руководству на [Launchpad](https://launchpad.ethereum.org/). Сделайте это на настольном компьютере/ноутбуке, но не генерируйте ключи — это можно сделать прямо на Raspberry Pi.

Инструмент [ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) генерирует ключи валидатора. Текущие образы включают его; если вы используете более старый образ, сначала установите его. Затем сгенерируйте ключи депозита, заменив `<YOUR_ETH_ADDRESS>` на адрес, который должен получать ваши выводы средств:

```sh
sudo apt-get update
sudo apt-get install ethstaker-deposit-cli
cd && deposit new-mnemonic --num_validators 1 --execution_address <YOUR_ETH_ADDRESS> --chain mainnet
```

(Или скачайте [ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) для запуска на изолированном от сети компьютере и выполните команду `deposit new-mnemonic` там)

Храните мнемоническую фразу в безопасности! Приведенная выше команда сгенерировала два файла в каталоге `validator_keys`: ключи валидатора и файл данных депозита. Данные депозита необходимо загрузить в Launchpad, поэтому их нужно скопировать с Raspberry Pi на настольный компьютер/ноутбук. Это можно сделать с помощью SSH-соединения или любого другого метода копирования/вставки.

Как только файл данных депозита станет доступен на компьютере, на котором запущен Launchpad, его можно перетащить на `+` на экране Launchpad. Следуйте инструкциям на экране, чтобы отправить транзакцию в депозитный контракт.

Вернувшись к Raspberry Pi, можно запустить валидатор. Для этого требуется импортировать ключи валидатора, установить адрес для сбора вознаграждений, а затем запустить предварительно настроенный процесс валидатора. Пример ниже приведен для Lighthouse — инструкции для других клиентов консенсуса доступны в [документации Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/staking/solo-staking.html):

```shell
# импортируйте ключи валидатора
lighthouse account validator import --directory=/home/ethereum/validator_keys

# установите адрес для вознаграждений (замените <YOUR_ETH_ADDRESS> на ваш адрес)
sudo sed -i 's/changeme/<YOUR_ETH_ADDRESS>/' /etc/ethereum/lighthouse-validator.conf

# запустите валидатор
sudo systemctl enable --now lighthouse-validator
```

Поздравляем, теперь у вас есть полноценный узел Эфириума и валидатор, работающие на Raspberry Pi!
