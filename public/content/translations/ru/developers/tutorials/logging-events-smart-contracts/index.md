В Solidity [события](/developers/docs/smart-contracts/anatomy/#events-and-logs) — это отправляемые сигналы, которые могут вызывать смарт-контракты. Децентрализованные приложения (dapp) или любые другие приложения, подключенные к API JSON-RPC Эфириума, могут прослушивать эти события и действовать соответствующим образом. Событие также может быть проиндексировано, чтобы историю событий можно было искать в дальнейшем.

## События {#events}

Одним из самых распространенных событий в блокчейне Эфириума является событие `Transfer`, которое генерируется токенами ERC-20, когда кто-то переводит токены.

```solidity
event Transfer(address indexed from, address indexed to, uint256 value);
```

Подпись события объявляется внутри кода контракта и может быть вызвана с помощью ключевого слова emit. Например, событие перевода записывает в лог, кто отправил перевод (_from_), кому (_to_) и сколько токенов было переведено (_value_).

Давайте вернемся к смарт-контракту `Counter` из руководства [развертывание вашего первого смарт-контракта](/developers/tutorials/deploying-your-first-smart-contract/) и будем записывать в лог каждое изменение значения. Это будет выглядеть так:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {

    event ValueChanged(uint256 oldValue, uint256 newValue);

    // Публичная переменная типа unsigned int для хранения значения счетчика
    uint256 public count = 0;

    // Функция, которая увеличивает наш счетчик
    function increment() public {
        count += 1;
        emit ValueChanged(count - 1, count);
    }

    // Необязательный геттер для получения значения счетчика
    function getCount() public view returns (uint256) {
        return count;
    }

}
```

Обратите внимание, что:

- **Строка 6**: мы объявляем наше событие и то, что оно содержит: старое и новое значения.

- **Строка 14**: Когда мы увеличиваем нашу переменную count, мы генерируем событие.

Если теперь мы развернем контракт и вызовем функцию increment, мы увидим, что Remix автоматически отобразит его, если вы нажмете на новую транзакцию внутри массива с именем logs.

![Скриншот Remix](./remix-screenshot.png)

Логи очень полезны для отладки ваших смарт-контрактов, но они также важны, если вы создаете приложения, используемые разными людьми, и упрощают аналитику для отслеживания и понимания того, как используется ваш смарт-контракт. Логи, сгенерированные транзакциями, отображаются в популярных обозревателях блоков, и вы также можете, например, использовать их для создания офчейн-скриптов для прослушивания определенных событий и выполнения действий при их возникновении.
