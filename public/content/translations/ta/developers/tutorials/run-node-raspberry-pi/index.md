**Ethereum on Arm என்பது Raspberry Pi-ஐ எத்திரியம் கணுவாக மாற்றக்கூடிய தனிப்பயன் Linux இமேஜ் ஆகும்.**

Raspberry Pi-ஐ எத்திரியம் கணுவாக மாற்ற Ethereum on Arm-ஐப் பயன்படுத்த, பின்வரும் வன்பொருள் பரிந்துரைக்கப்படுகிறது:

- 16 GB RAM கொண்ட Raspberry Pi 5
- NVMe வட்டை இணைக்க, Raspberry Pi 5-க்கான NVMe HAT
- NVMe SSD (M.2 2280), குறைந்தபட்சம் 4 TB. Phison கன்ட்ரோலர் கொண்ட வட்டுகளைத் தவிர்க்கவும், ஏனெனில் அவற்றில் பொருந்தக்கூடிய சிக்கல்கள் உள்ளன.
- MicroSD கார்டு (குறைந்தபட்சம் 16 GB Class 10)
- மின்சாரம் (Power supply)
- ஈத்தர்நெட் கேபிள்
- போர்ட் ஃபார்வர்டிங் (மேலும் தகவலுக்கு கிளையண்டுகளைப் பார்க்கவும்)
- ஹீட்சிங்க் கொண்ட உறை (case)
- USB கீபோர்டு, மானிட்டர் மற்றும் HDMI கேபிள் (micro-HDMI) (விருப்பத்திற்குரியது)

Ethereum on Arm ஆனது NanoPC T6, Rock 5B மற்றும் Orange Pi 5 Plus போன்ற பிற ARM போர்டுகளையும் ஆதரிக்கிறது. இந்த போர்டுகள் நேட்டிவ் NVMe ஆதரவைக் கொண்டுள்ளன, எனவே நீங்கள் புதிய வன்பொருளை வாங்குகிறீர்கள் என்றால் Raspberry Pi 5-ஐ விட இவற்றை Ethereum on Arm குழு பரிந்துரைக்கிறது. விவரங்களுக்கு [பரிந்துரைக்கப்பட்ட வன்பொருள் பட்டியலைப்](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/overview/supported-hardware.html) பார்க்கவும். நீங்கள் பதிவிறக்கும் இமேஜ் கோப்பைத் தவிர, இந்த டுடோரியலின் மீதமுள்ளவை ஆதரிக்கப்படும் அனைத்து போர்டுகளுக்கும் ஒரே மாதிரியானவை.

## ARM-இல் எத்திரியத்தை ஏன் இயக்க வேண்டும்? {#why-run-ethereum-on-arm}

ARM போர்டுகள் மிகவும் மலிவான, நெகிழ்வான, சிறிய கணினிகள் ஆகும். எத்திரியம் கணுக்களை இயக்குவதற்கு இவை சிறந்த தேர்வுகளாகும், ஏனெனில் இவற்றை மலிவாக வாங்கலாம், அவற்றின் அனைத்து வளங்களும் கணுவில் மட்டுமே கவனம் செலுத்துமாறு கட்டமைக்கலாம், இதனால் அவை திறமையானவையாக மாறுகின்றன, குறைந்த அளவு மின்சாரத்தையே பயன்படுத்துகின்றன மற்றும் உடல் ரீதியாக சிறியதாக இருப்பதால் எந்த வீட்டிலும் தடையின்றி பொருத்த முடியும். Raspberry Pi-இன் MicroSD-ஐ முன்பே உருவாக்கப்பட்ட இமேஜ் மூலம் எளிதாக ஃபிளாஷ் செய்ய முடியும் என்பதால், மென்பொருளைப் பதிவிறக்கவோ அல்லது உருவாக்கவோ தேவையில்லாமல் கணுக்களைத் தொடங்குவதும் மிகவும் எளிதானது.

## இது எவ்வாறு செயல்படுகிறது? {#how-does-it-work}

Raspberry Pi-இன் மெமரி கார்டு முன்பே உருவாக்கப்பட்ட இமேஜ் மூலம் ஃபிளாஷ் செய்யப்படுகிறது. இந்த இமேஜில் எத்திரியம் கணுவை இயக்கத் தேவையான அனைத்தும் உள்ளன. ஃபிளாஷ் செய்யப்பட்ட கார்டு மூலம், பயனர் செய்ய வேண்டியதெல்லாம் Raspberry Pi-ஐ இயக்குவது மட்டுமே. கணுவை இயக்கத் தேவையான அனைத்து செயல்முறைகளும் தானாகவே தொடங்கப்படும். மெமரி கார்டில் Linux அடிப்படையிலான இயங்குதளம் (OS) இருப்பதால் இது சாத்தியமாகிறது, இதன் மேல் கணினி அளவிலான செயல்முறைகள் தானாகவே இயங்கி யூனிட்டை எத்திரியம் கணுவாக மாற்றுகின்றன.

Ethereum on Arm இமேஜ்கள் எத்திரியம் கணுவை இயக்குவதற்கு உகந்ததாக உள்ள 64-பிட் Linux விநியோகத்தை அடிப்படையாகக் கொண்டவை, மேலும் அவை முன்பே உருவாக்கப்பட்ட எத்திரியம் கிளையண்டுகளை உள்ளடக்கியுள்ளன.

சுற்றுச்சூழலை அமைப்பது மற்றும் NVMe வட்டை ஃபார்மேட் செய்வது முதல் எத்திரியம் மென்பொருளை நிறுவுவது வரை **தேவையான அனைத்து படிகளையும் இமேஜ்கள் கவனித்துக்கொள்கின்றன**.

## செயலாக்க மற்றும் ஒருமித்த கிளையண்டுகள் பற்றிய குறிப்பு {#note-on-execution-and-consensus-clients}

Ethereum on Arm இமேஜில் முன்பே உருவாக்கப்பட்ட செயலாக்க மற்றும் ஒருமித்த கிளையண்டுகள் சேவைகளாக உள்ளன. ஒரு எத்திரியம் கணுவிற்கு இரண்டு கிளையண்டுகளும் ஒத்திசைக்கப்பட்டு இயங்க வேண்டும். நீங்கள் இமேஜைப் பதிவிறக்கி ஃபிளாஷ் செய்து, பின்னர் சேவைகளைத் தொடங்கினால் மட்டுமே போதுமானது. இமேஜில் பல செயலாக்கக் கிளையண்டுகள் (Geth, Nethermind, Besu, Erigon மற்றும் Reth போன்றவை) மற்றும் ஒருமித்த கிளையண்டுகள் (Lighthouse, Prysm, Teku, Nimbus மற்றும் Lodestar போன்றவை) முன்பே ஏற்றப்பட்டுள்ளன. தற்போதைய பட்டியலுக்கு [Ethereum on Arm ஆவணங்களைப்](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/running-a-node/managing-clients.html) பார்க்கவும்.

இயக்குவதற்கு ஒவ்வொன்றிலும் ஒன்றை நீங்கள் தேர்வு செய்ய வேண்டும் - அனைத்து செயலாக்கக் கிளையண்டுகளும் அனைத்து ஒருமித்த கிளையண்டுகளுடனும் இணக்கமானவை. இந்த டுடோரியல் Geth மற்றும் Lighthouse-ஐப் பயன்படுத்துகிறது.

## இமேஜைப் பதிவிறக்குதல் {#downloading-the-image}

Ethereum on Arm இமேஜ் என்பது "பிளக் அண்ட் ப்ளே" இமேஜ் ஆகும், இது செயலாக்க மற்றும் ஒருமித்த கிளையண்டுகள் இரண்டையும் தானாகவே நிறுவி அமைக்கிறது, அவை ஒன்றுக்கொன்று பேசவும் எத்திரியம் பிணையத்துடன் இணைக்கவும் கட்டமைக்கிறது. பயனர் செய்ய வேண்டியதெல்லாம் ஒரு எளிய கட்டளையைப் பயன்படுத்தி அவற்றின் செயல்முறைகளைத் தொடங்குவது மட்டுமே.

[Ethereum on Arm பதிவிறக்கப் பக்கத்திலிருந்து](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/getting-started/installation.html#image-downloads) உங்கள் போர்டுக்கான சமீபத்திய இமேஜைப் பதிவிறக்கவும். பதிவிறக்கப் பக்கம் ஒவ்வொரு இமேஜின் SHA-256 செக்சம்மையும் பட்டியலிடுகிறது. பதிவிறக்கப்பட்ட கோப்பை அதனுடன் சரிபார்க்கவும்:

```sh
# பதிவிறக்கப்பட்ட படிமம் உள்ள கோப்பகத்திலிருந்து
sha256sum ethonarm_rpi5_<version>.img.zip
# பதிவிறக்கப் பக்கத்தில் உள்ள செக்சம்முடன் வெளியீட்டை ஒப்பிடுக
```

## MicroSD-ஐ ஃபிளாஷ் செய்தல் {#flashing-the-microsd}

Raspberry Pi-க்கு பயன்படுத்தப்படும் MicroSD கார்டை முதலில் டெஸ்க்டாப் அல்லது லேப்டாப்பில் செருக வேண்டும், அப்போதுதான் அதை ஃபிளாஷ் செய்ய முடியும். பின்னர், பின்வரும் டெர்மினல் கட்டளைகள் பதிவிறக்கப்பட்ட இமேஜை SD கார்டில் ஃபிளாஷ் செய்யும்:

```shell
# MicroSD கார்டின் பெயரைச் சரிபார்க்கவும்
sudo fdisk -l

>> sdxxx
```

பெயரைச் சரியாகப் பெறுவது மிகவும் முக்கியம், ஏனெனில் அடுத்த கட்டளையில் `dd` உள்ளது, இது இமேஜை கார்டில் தள்ளுவதற்கு முன்பு கார்டின் தற்போதைய உள்ளடக்கத்தை முழுமையாக அழித்துவிடும். தொடர, ஜிப் செய்யப்பட்ட இமேஜ் உள்ள கோப்பகத்திற்குச் செல்லவும்:

```shell
# அன்சிப் செய்து படிமத்தை ஃப்ளாஷ் செய்யவும்
unzip ethonarm_rpi5_<version>.img.zip
sudo dd bs=1M if=ethonarm_rpi5_<version>.img of=/dev/<sdxx> conv=fdatasync status=progress
```

கார்டு இப்போது ஃபிளாஷ் செய்யப்பட்டுவிட்டது, எனவே அதை Raspberry Pi-இல் செருகலாம்.

## கணுவைத் தொடங்குதல் {#start-the-node}

Raspberry Pi-இல் SD கார்டைச் செருகியவுடன், ஈத்தர்நெட் கேபிள் மற்றும் NVMe வட்டை இணைத்து, பின்னர் மின்சாரத்தை இயக்கவும். OS பூட் ஆகி, NVMe வட்டை ஃபார்மேட் செய்வது மற்றும் கிளையன்ட் மென்பொருளை நிறுவுவது உட்பட, Raspberry Pi-ஐ எத்திரியம் கணுவாக மாற்றும் முன்-கட்டமைக்கப்பட்ட பணிகளைத் தானாகவே செய்யத் தொடங்கும். இதற்கு 10-15 நிமிடங்கள் ஆகலாம், மேலும் இது முடிந்ததும் போர்டு தானாகவே ரீபூட் ஆகும். இந்த நேரத்தில் மின்சார விநியோகத்தை நிறுத்த வேண்டாம்.

அனைத்தும் நிறுவப்பட்டு கட்டமைக்கப்பட்டவுடன், ssh இணைப்பு வழியாக அல்லது போர்டில் மானிட்டர் மற்றும் கீபோர்டு இணைக்கப்பட்டிருந்தால் நேரடியாக டெர்மினலைப் பயன்படுத்தி சாதனத்தில் உள்நுழையவும். கணுவைத் தொடங்கத் தேவையான அனுமதிகளைக் கொண்டுள்ளதால், உள்நுழைய `ethereum` கணக்கைப் பயன்படுத்தவும்.

```shell
User: ethereum
Password: ethereum
```

உங்கள் முதல் உள்நுழைவில் இயல்புநிலை கடவுச்சொல்லை மாற்றுமாறு கேட்கப்படுவீர்கள். அதைச் செய்யுங்கள், ஏனெனில் உங்கள் கணுவை அணுகக்கூடிய எவரும் இயல்புநிலை கடவுச்சொல்லுடன் உள்நுழைய முடியும். கணினி ஃபயர்வால் இயல்புநிலையாக முடக்கப்பட்டுள்ளது, எனவே உங்கள் கணு பொது IP முகவரியைக் கொண்டிருந்தால், அதை இயக்க [Ethereum on Arm பாதுகாப்பு வழிகாட்டியைப்](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/system/security.html) பார்க்கவும்.

முதலில் ஒருமித்த கிளையண்டைத் தொடங்கவும். உங்கள் ரவுட்டரில் போர்ட் 9000-ஐ (TCP மற்றும் UDP) திறக்கவும், இதனால் Lighthouse பியர்களைக் கண்டுபிடித்து இணைக்க முடியும். பின்னர் lighthouse சேவையை இயக்கித் தொடங்கவும், இதனால் ரீபூட்டிற்குப் பிறகும் அது மறுதொடக்கம் செய்யப்படும்:

```sh
sudo systemctl enable --now lighthouse-beacon
```

பதிவுகளைப் பயன்படுத்தி கிளையண்ட்டைச் சரிபார்க்கவும்:

```sh
sudo journalctl -u lighthouse-beacon -f
```

அடுத்து, செயலாக்கக் கிளையண்டைத் தொடங்கவும். உங்கள் ரவுட்டரில் போர்ட் 30303-ஐ (TCP மற்றும் UDP) திறக்கவும், இதனால் Geth பியர்களைக் கண்டுபிடித்து இணைக்க முடியும். பின்னர் geth சேவையை இயக்கித் தொடங்கவும்:

```sh
sudo systemctl enable --now geth
```

பதிவுகளைச் சரிபார்ப்பதன் மூலம் அது இயங்குவதை நீங்கள் உறுதிப்படுத்தலாம்:

```sh
sudo journalctl -u geth -f
```

ஒருமித்த கிளையன்ட் சரிபார்ப்புப் புள்ளி ஒத்திசைவைப் பயன்படுத்துவதால் சில நிமிடங்களில் ஒத்திசைக்கப்படும் என்பதை நினைவில் கொள்ளவும். செயலாக்கக் கிளையண்டிற்கு அதிக நேரம் எடுக்கும் - பல மணிநேரங்கள் ஆகலாம். இரண்டு கிளையண்டுகளும் ஒரே நேரத்தில் இயங்குகின்றன: சங்கிலியின் தலைப்பகுதியில் எந்தத் தொகுதி உள்ளது என்பதை ஒருமித்த கிளையன்ட் செயலாக்கக் கிளையண்டிற்குச் சொல்கிறது, மேலும் செயலாக்கக் கிளையன்ட் அதுவரையிலான தொகுதிகளைப் பதிவிறக்கி சரிபார்க்கிறது.

Geth மற்றும் Lighthouse சேவைகள் இயங்கி ஒத்திசைக்கப்பட்ட நிலையில், உங்கள் Raspberry Pi இப்போது ஒரு எத்திரியம் கணுவாகும்! போர்ட் 8545-இல் Geth கிளையண்ட்டுடன் இணைக்கக்கூடிய Geth-இன் JavaScript கன்சோலைப் பயன்படுத்தி எத்திரியம் பிணையத்துடன் தொடர்புகொள்வது மிகவும் பொதுவானது. Curl போன்ற கோரிக்கை கருவியைப் பயன்படுத்தி JSON ஆப்ஜெக்ட்களாக வடிவமைக்கப்பட்ட கட்டளைகளைச் சமர்ப்பிக்கவும் முடியும். [Geth ஆவணங்களில்](https://geth.ethereum.org/) மேலும் பார்க்கவும்.

இமேஜில் Grafana டேஷ்போர்டும் உள்ளது, மேம்பட்ட பயனர்கள் உலாவியில் `ipaddress:3000` என்பதற்குச் செல்வதன் மூலம் தங்கள் கணுவின் ஆரோக்கியத்தைக் கண்காணிக்க இதைப் பயன்படுத்தலாம்.

## சரிபார்ப்பான்கள் {#validators}

ஒருமித்த கிளையண்டில் விருப்பத்தின் பேரில் ஒரு சரிபார்ப்பானையும் சேர்க்கலாம். சரிபார்ப்பான் மென்பொருள் உங்கள் கணுவை ஒருமித்த கருத்தில் தீவிரமாகப் பங்கேற்க அனுமதிக்கிறது மற்றும் பிணையத்திற்கு கிரிப்டோ-பொருளாதாரப் பாதுகாப்பை வழங்குகிறது. இந்தப் பணிக்காக உங்களுக்கு ETH-இல் வெகுமதி கிடைக்கும். ஒரு சரிபார்ப்பானை இயக்க, உங்களிடம் முதலில் 32 ETH இருக்க வேண்டும், அதை வைப்பு ஒப்பந்தத்தில் டெபாசிட் செய்ய வேண்டும். [Launchpad](https://launchpad.ethereum.org/)-இல் உள்ள படிப்படியான வழிகாட்டியைப் பின்பற்றுவதன் மூலம் டெபாசிட் செய்யலாம். இதை டெஸ்க்டாப்/லேப்டாப்பில் செய்யுங்கள், ஆனால் விசைகளை உருவாக்க வேண்டாம் — இதை நேரடியாக Raspberry Pi-இலேயே செய்யலாம்.

[ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) கருவி சரிபார்ப்பான் விசைகளை உருவாக்குகிறது. தற்போதைய இமேஜ்களில் இது உள்ளது; நீங்கள் பழைய இமேஜை இயக்குகிறீர்கள் என்றால், முதலில் அதை நிறுவவும். பின்னர் டெபாசிட் விசைகளை உருவாக்கவும், `<YOUR_ETH_ADDRESS>` என்பதை உங்கள் திரும்பப் பெறுதல்களைப் பெற வேண்டிய முகவரியுடன் மாற்றவும்:

```sh
sudo apt-get update
sudo apt-get install ethstaker-deposit-cli
cd && deposit new-mnemonic --num_validators 1 --execution_address <YOUR_ETH_ADDRESS> --chain mainnet
```

(அல்லது ஏர்கேப்டு (airgapped) கணினியில் இயக்க [ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli)-ஐப் பதிவிறக்கி, அங்கு `deposit new-mnemonic` கட்டளையை இயக்கவும்)

நினைவூட்டல் சொற்றொடரைப் பாதுகாப்பாக வைத்திருங்கள்! மேலே உள்ள கட்டளை `validator_keys` கோப்பகத்தில் இரண்டு கோப்புகளை உருவாக்கியது: சரிபார்ப்பான் விசைகள் மற்றும் டெபாசிட் தரவுக் கோப்பு. டெபாசிட் தரவை லாஞ்ச்பேடில் பதிவேற்ற வேண்டும், எனவே அதை Raspberry Pi-இலிருந்து டெஸ்க்டாப்/லேப்டாப்பிற்கு நகலெடுக்க வேண்டும். ssh இணைப்பு அல்லது வேறு ஏதேனும் நகலெடுக்கும்/ஒட்டும் முறையைப் பயன்படுத்தி இதைச் செய்யலாம்.

லாஞ்ச்பேடை இயக்கும் கணினியில் டெபாசிட் தரவுக் கோப்பு கிடைத்தவுடன், அதை லாஞ்ச்பேடு திரையில் உள்ள `+` மீது இழுத்து விடலாம். வைப்பு ஒப்பந்தத்திற்குப் பரிவர்த்தனையை அனுப்ப திரையில் உள்ள வழிமுறைகளைப் பின்பற்றவும்.

மீண்டும் Raspberry Pi-இல், ஒரு சரிபார்ப்பானைத் தொடங்கலாம். இதற்கு சரிபார்ப்பான் விசைகளை இறக்குமதி செய்வது, வெகுமதிகளைச் சேகரிக்க முகவரியை அமைப்பது மற்றும் முன்-கட்டமைக்கப்பட்ட சரிபார்ப்பான் செயல்முறையைத் தொடங்குவது ஆகியவை தேவை. கீழே உள்ள எடுத்துக்காட்டு Lighthouse-க்கானது—பிற ஒருமித்த கிளையண்டுகளுக்கான வழிமுறைகள் [Ethereum on Arm ஆவணங்களில்](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/staking/solo-staking.html) கிடைக்கின்றன:

```shell
# சரிபார்ப்பான் திறவுகோல்களை இறக்குமதி செய்யவும்
lighthouse account validator import --directory=/home/ethereum/validator_keys

# வெகுமதி முகவரியை அமைக்கவும் (<YOUR_ETH_ADDRESS> என்பதை உங்கள் முகவரியைக் கொண்டு மாற்றவும்)
sudo sed -i 's/changeme/<YOUR_ETH_ADDRESS>/' /etc/ethereum/lighthouse-validator.conf

# சரிபார்ப்பானைத் தொடங்கவும்
sudo systemctl enable --now lighthouse-validator
```

வாழ்த்துக்கள், இப்போது உங்களிடம் Raspberry Pi-இல் இயங்கும் முழுமையான எத்திரியம் கணு மற்றும் சரிபார்ப்பான் உள்ளது!

## மேலும் விவரங்கள் {#more-details}

Raspberry Pi-ஐப் பயன்படுத்தி கெத்-லைட்ஹவுஸ் கணு மற்றும் சரிபார்ப்பானை எவ்வாறு அமைப்பது என்பதற்கான மேலோட்டத்தை இந்தப் பக்கம் வழங்கியது. மேலும் விரிவான வழிமுறைகள் [Ethereum-on-Arm இணையதளத்தில்](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/) கிடைக்கின்றன.

## கருத்துகள் வரவேற்கப்படுகின்றன {#feedback-appreciated}

Raspberry Pi-க்கு மிகப்பெரிய பயனர் தளம் உள்ளது என்பதை நாங்கள் அறிவோம், இது எத்திரியம் பிணையத்தின் ஆரோக்கியத்தில் மிகவும் நேர்மறையான தாக்கத்தை ஏற்படுத்தும்.
தயவுசெய்து இந்த டுடோரியலில் உள்ள விவரங்களை ஆராயவும், டெஸ்ட்நெட்களில் இயக்க முயற்சிக்கவும், [Ethereum on Arm GitHub](https://github.com/EOA-Blockchain-Labs/ethereumonarm)-ஐப் பார்க்கவும், கருத்துகளை வழங்கவும், சிக்கல்கள் மற்றும் புல் கோரிக்கைகளை (pull requests) எழுப்பவும், மேலும் தொழில்நுட்பம் மற்றும் ஆவணங்களை மேம்படுத்த உதவவும்!
