Solidity-இல், [நிகழ்வுகள்](/developers/docs/smart-contracts/anatomy/#events-and-logs) என்பவை திறன் ஒப்பந்தங்கள் அனுப்பக்கூடிய சமிக்ஞைகள் ஆகும். பரவலாக்கப்பட்ட செயலிகள் (dapps) அல்லது எத்திரியம் ஜேசன்-ஆர்பிசி API உடன் இணைக்கப்பட்ட எதுவும் இந்த நிகழ்வுகளைக் கவனித்து அதற்கேற்ப செயல்பட முடியும். ஒரு நிகழ்வை அட்டவணைப்படுத்தவும் முடியும், இதனால் நிகழ்வு வரலாற்றை பின்னர் தேடலாம்.

## நிகழ்வுகள் {#events}

எத்திரியம் தொகுதிச்சங்கிலியில் மிகவும் பொதுவான நிகழ்வுகளில் ஒன்று `Transfer` நிகழ்வாகும், இது யாராவது டோக்கன்களைப் பரிமாற்றம் செய்யும்போது ERC-20 டோக்கன்களால் வெளியிடப்படுகிறது.

```solidity
event Transfer(address indexed from, address indexed to, uint256 value);
```

நிகழ்வு கையொப்பம் ஒப்பந்தக் குறியீட்டிற்குள் அறிவிக்கப்படுகிறது மற்றும் emit முக்கியச்சொல்லுடன் வெளியிடப்படலாம். எடுத்துக்காட்டாக, பரிமாற்ற நிகழ்வு யார் பரிமாற்றத்தை அனுப்பினார் (_from_), யாருக்கு (_to_) மற்றும் எவ்வளவு டோக்கன்கள் பரிமாற்றம் செய்யப்பட்டன (_value_) என்பதைப் பதிவு செய்கிறது.

[உங்கள் முதல் திறன் ஒப்பந்தத்தை நிலைநிறுத்துதல்](/developers/tutorials/deploying-your-first-smart-contract/) என்பதிலிருந்து `Counter` திறன் ஒப்பந்தத்திற்குத் திரும்பி, ஒவ்வொரு முறையும் மதிப்பு மாற்றப்படும்போது பதிவு செய்வோம். இது இப்படி இருக்கும்:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {

    event ValueChanged(uint256 oldValue, uint256 newValue);

    // எண்ணிக்கைகளை வைத்திருக்க unsigned int வகையிலான பொது மாறி
    uint256 public count = 0;

    // நமது எண்ணியை அதிகரிக்கும் செயல்பாடு
    function increment() public {
        count += 1;
        emit ValueChanged(count - 1, count);
    }

    // எண்ணிக்கை மதிப்பைப் பெறுவதற்கான அவசியமில்லாத கெட்டர் (getter)
    function getCount() public view returns (uint256) {
        return count;
    }

}
```

கவனிக்கவும்:

- **வரி 6**: எங்கள் நிகழ்வு மற்றும் அதில் என்ன உள்ளது, பழைய மதிப்பு மற்றும் புதிய மதிப்பு ஆகியவற்றை நாங்கள் அறிவிக்கிறோம்.

- **வரி 14**: எங்கள் count மாறியை அதிகரிக்கும்போது, நாங்கள் நிகழ்வை வெளியிடுகிறோம்.

இப்போது நாம் ஒப்பந்தத்தை நிலைநிறுத்தி, increment செயல்பாட்டை அழைத்தால், logs என்ற பெயரிலான அணிவரிசைக்குள் புதிய பரிவர்த்தனையைக் கிளிக் செய்தால் Remix தானாகவே அதைக் காண்பிப்பதைக் காண்போம்.

உங்கள் திறன் ஒப்பந்தங்களில் உள்ள பிழைகளைத் திருத்துவதற்குப் பதிவுகள் மிகவும் பயனுள்ளதாக இருக்கும், ஆனால் வெவ்வேறு நபர்களால் பயன்படுத்தப்படும் செயலிகளை நீங்கள் உருவாக்கினால் அவை முக்கியமானவை, மேலும் உங்கள் திறன் ஒப்பந்தம் எவ்வாறு பயன்படுத்தப்படுகிறது என்பதைக் கண்காணிக்கவும் புரிந்துகொள்ளவும் பகுப்பாய்வுகளை எளிதாக்குகிறது. பரிவர்த்தனைகளால் உருவாக்கப்படும் பதிவுகள் பிரபலமான தொகுதி எக்ஸ்ப்ளோரர்களில் காட்டப்படும், மேலும் குறிப்பிட்ட நிகழ்வுகளைக் கேட்பதற்கும் அவை நிகழும்போது நடவடிக்கை எடுப்பதற்கும் புறச்சங்கிலி ஸ்கிரிப்ட்களை உருவாக்க அவற்றைப் பயன்படுத்தலாம்.
