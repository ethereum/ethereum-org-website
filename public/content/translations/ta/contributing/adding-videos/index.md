[ethereum.org காணொளித் தொகுப்பு](/videos/) சமூகப் படைப்பாளர்கள் மற்றும் நம்பகமான மூலங்களிலிருந்து எத்திரியம் மற்றும் எத்திரியம் சுற்றுச்சூழல் அமைப்பு பற்றிய காணொளிகளைக் கொண்டுள்ளது. காணொளியைச் சேர்க்க யார் வேண்டுமானாலும் பரிந்துரைக்கலாம்.

## பட்டியலிடல் கொள்கை {#listing-policy}

Ethereum.org ஒரு நடுநிலையான, கல்வி சார்ந்த வளமாகும். காணொளித் தொகுப்பு இதற்காகத் தொகுக்கப்பட்டுள்ளது:

- எத்திரியம் தொழில்நுட்பம், சுற்றுச்சூழல் அமைப்பு மற்றும் சமூகம் பற்றி பயனர்களுக்கு **கற்பிக்க**
- அதன் தொழில்நுட்ப உள்ளடக்கத்தில் **துல்லியமாக இருக்க**
- எத்திரியம் சமூகத்திற்கு **பொருத்தமானதாக இருக்க**

ஒரு குறிப்பிட்ட தயாரிப்பு, வில்லை அல்லது வணிகச் சேவையை முதன்மையாக விளம்பரப்படுத்தும் காணொளிகளை இந்தத் தளம் பட்டியலிடுவதில்லை.

## சேர்ப்பதற்கான அளவுகோல்கள் {#criteria-for-inclusion}

### கட்டாயம் இருக்க வேண்டியவை {#must-haves}

- **எத்திரியத்தை மையமாகக் கொண்டவை** – காணொளி முதன்மையாக எத்திரியம், அதன் தொழில்நுட்பம், சுற்றுச்சூழல் அமைப்பு அல்லது சமூகம் பற்றியதாக இருக்க வேண்டும். பொதுவான தொகுதிச்சங்கிலி தலைப்புகள் பற்றிய காணொளிகள், தளத்தில் உள்ள ஒரு கல்விப் பக்கத்தை கணிசமாக ஆதரித்தால் அல்லது அதனுடன் தொடர்புடையதாக இருந்தால் அல்லது எத்திரியத்தைக் குறிப்பிட்டால் மட்டுமே ஏற்றுக்கொள்ளப்படும்.
- **கல்வி மதிப்பு** – காணொளி பார்வையாளர்களுக்கு எத்திரியம் பற்றி ஏதாவது கற்பிக்க வேண்டும் அல்லது உலகளாவிய எத்திரியம் சமூகத்தைக் கொண்டாட வேண்டும். விளம்பர அல்லது சந்தைப்படுத்தல் உள்ளடக்கம் ஏற்றுக்கொள்ளப்படாது.
- **துல்லியமான தகவல்** – தொழில்நுட்ப உள்ளடக்கம் உண்மையாக சரியாகவும் புதுப்பித்த நிலையிலும் இருக்க வேண்டும். கைவிடப்பட்ட அம்சங்கள் பற்றிய காலாவதியான காணொளிகள் அகற்றப்படலாம்.
- **தரமான தயாரிப்பு** – காணொளி நியாயமான தெளிவான ஆடியோ மற்றும் வீடியோ தரத்தைக் கொண்டிருக்க வேண்டும்.
- **பொதுவில் கிடைக்கக்கூடியவை** – காணொளி திறந்த வளம் அல்லது யூடியூப் போன்ற அணுகக்கூடிய தளத்தில் வழங்கப்பட வேண்டும், மேலும் கட்டணச் சுவர் அல்லது பதிவு செய்யும் தேவை இல்லாமல் இலவசமாக அணுகக்கூடியதாக இருக்க வேண்டும்.

### இருந்தால் நல்லவை {#nice-to-haves}

- **படியெடுத்தல் (transcript) கொண்டவை** – படியெடுத்தல் கொண்ட காணொளிகள் அணுகல்தன்மை மற்றும் SEO-ஐ மேம்படுத்துகின்றன. உங்களிடம் ஒன்று இல்லையென்றால், அதை உருவாக்க ethereum.org குழு உதவலாம்.
- **நம்பகமான மூலத்திலிருந்து** – நிறுவப்பட்ட கல்வியாளர்கள், ஆராய்ச்சியாளர்கள் மற்றும் மூலங்களிலிருந்து வரும் உள்ளடக்கத்திற்கு முன்னுரிமை அளிக்கப்படுகிறது.
- **சரியான நேரத்திலும் எப்போதும் பொருத்தமானதாகவும்** – காலப்போக்கில் பொருத்தமானதாக இருக்கும் உள்ளடக்கத்திற்கு, நேரத்தை உணரும் பொருளை விட முன்னுரிமை அளிக்கப்படுகிறது.

## காணொளியை எவ்வாறு சேர்ப்பது {#how-to-add-a-video}

### விருப்பம் 1: ஒரு சிக்கலை (issue) திறக்கவும் {#open-an-issue}

நீங்கள் ஒரு காணொளியைப் பரிந்துரைக்க விரும்பினால், ஆனால் கோப்புகளை நீங்களே உருவாக்க விரும்பவில்லை என்றால், காணொளி விவரங்களுடன் ஒரு GitHub சிக்கலைத் திறக்கவும், அதைச் சேர்க்க ஒரு பங்களிப்பாளர் உங்களுக்கு உதவலாம்.

<ButtonLink href="https://github.com/ethereum/ethereum-org-website/issues/new?template=suggest_video.yaml">
  காணொளியைப் பரிந்துரைக்கவும்
</ButtonLink>

### விருப்பம் 2: ஒரு இழுப்பு கோரிக்கையைத் (pull request) திறக்கவும் {#open-a-pull-request}

காணொளியை நீங்களே சேர்க்க விரும்பினால், இந்தப் படிகளைப் பின்பற்றவும்:

#### படி 1: காணொளிக் கோப்பை உருவாக்கவும் {#step-1}

புதிய கோப்பகத்தையும் `index.md` கோப்பையும் இங்கே உருவாக்கவும்:

```
public/content/videos/{your-video-slug}/index.md
```

ஸ்லக் (slug) URL-பாதுகாப்பானதாகவும், சிறிய எழுத்துக்களிலும், ஹைபன்களைப் பயன்படுத்தியும் இருக்க வேண்டும் (எ.கா., `blockchain-101-visual-demo`).

#### படி 2: முன்விவரத்தைச் (frontmatter) சேர்க்கவும் {#step-2}

பின்வரும் YAML முன்விவரத்தை உங்கள் `index.md` இல் சேர்க்கவும்:

```yaml
---
title: "Your Video Title"
description: "A brief 1–3 sentence summary of the video."
lang: en
youtubeId: "dQw4w9WgXcQ"
uploadDate: 2025-01-15
duration: "12:30"
educationLevel: beginner
topic:
  - "your-topic"
  - "another-topic"
format: explainer
author: Channel Name
---
```

**புலக் குறிப்பு:**

| புலம் | தேவையானது | விளக்கம் |
|---|---|---|
| `title` | ஆம் | காணொளித் தலைப்பு |
| `description` | ஆம் | 1–3 வாக்கியச் சுருக்கம் |
| `lang` | ஆம் | இப்போதைக்கு எப்போதும் `en` |
| `youtubeId` | ஆம் | யூடியூப் காணொளி ID (`v=` க்குப் பிறகு உள்ள URL இலிருந்து) |
| `uploadDate` | ஆம் | `YYYY-MM-DD` வடிவத்தில் அசல் பதிவேற்றத் தேதி |
| `duration` | ஆம் | காணொளியின் நீளம் `H:MM:SS` அல்லது `M:SS` ஆக |
| `educationLevel` | ஆம் | `beginner`, `intermediate`, அல்லது `advanced` |
| `topic` | ஆம் | தொகுப்பு வடிகட்டலுக்கான தலைப்புக் குறிகளின் (tags) வரிசை |
| `format` | ஆம் | `explainer`, `presentation`, `interview`, `tutorial`, அல்லது `panel` |
| `author` | ஆம் | படைப்பாளர் அல்லது சேனல் பெயர் |
| `breadcrumb` | இல்லை | பிரெட்க்ரம்ப் (breadcrumb) வழிசெலுத்தலுக்கான தனிப்பயன் குறுகிய லேபிள் |
| `customThumbnailUrl` | இல்லை | தனிப்பயன் சிறுபடம் URL (இயல்புநிலையாக யூடியூப் சிறுபடம்) |

#### படி 3: படியெடுத்தலைச் சேர்க்கவும் (பரிந்துரைக்கப்படுகிறது) {#step-3}

முன்விவர `---` க்கு கீழே, காணொளிப் படியெடுத்தலை மார்க்டவுன் வடிவத்தில் சேர்க்கவும்:

```markdown
---
title: "..."
# ... முன்விவரத்தின் மீதமுள்ளவை
---

காணொளி உள்ளடக்கம் பற்றிய சுருக்கமான அறிமுகம்.

### பிரிவுத் தலைப்பு (0:00)

இந்தப் பிரிவுக்கான படியெடுத்தல் உரை...

### அடுத்தப் பிரிவு (5:30)

மேலும் படியெடுத்தல் உரை...
```

முக்கியப் பிரிவுகளைக் குறிக்க நேர முத்திரைகளுடன் `###` தலைப்புகளைப் பயன்படுத்தவும். இது படியெடுத்தலை ஸ்கேன் செய்யக்கூடியதாக ஆக்குகிறது மற்றும் SEO-ஐ மேம்படுத்துகிறது.

உங்களிடம் படியெடுத்தல் இல்லையென்றால், நீங்கள் உடற்பகுதியை காலியாக விடலாம், குழு ஒன்றை உருவாக்கும்.

#### படி 4: தலைப்புக் குறிகளைத் தேர்ந்தெடுக்கவும் {#step-4}

கீழே உள்ள பட்டியலிலிருந்து தலைப்புக் குறிகளைத் தேர்ந்தெடுக்கவும். ஒவ்வொரு குறியும் காணொளித் தொகுப்பில் உள்ள வடிகட்டி வகையுடன் நேரடியாக வரைபடமாக்கப்படுகிறது — காட்டப்பட்டுள்ளபடியே குறிப் பெயரைப் பயன்படுத்தவும்.

பல தொகுப்பு வடிகட்டிகளில் தோன்றுவதற்கு ஒரு காணொளி பல குறிகளைக் கொண்டிருக்கலாம்:

| குறி | தொகுப்பு வடிகட்டி |
|---|---|
| `how-ethereum-works` | எத்திரியம் எவ்வாறு செயல்படுகிறது |
| `network-upgrades` | பிணைய மேம்படுத்தல்கள் |
| `roadmap-and-priorities` | திட்ட வரைபடம் மற்றும் முன்னுரிமைகள் |
| `scaling-and-layer-2` | அளவிடுதல் மற்றும் அடுக்கு 2 (l2) |
| `use-cases` | பயன்பாட்டு நேர்வுகள் |
| `privacy` | தனியுரிமை |
| `security` | பாதுகாப்பு |
| `community-stories` | சமூகக் கதைகள் |
| `events` | நிகழ்வுகள் |

ஒவ்வொரு காணொளியும் இந்தப் பட்டியலிலிருந்து குறைந்தது ஒரு குறியையாவது கொண்டிருக்க வேண்டும். அங்கீகரிக்கப்பட்ட குறி இல்லாத காணொளிகள் "அனைத்தும்" பார்வை மற்றும் தேடல் முடிவுகளில் மட்டுமே தோன்றும்.

`community-stories` குறியானது ஒரு காணொளியை [கதைகள் பக்கத்திலும்](/stories/) தோன்றச் செய்கிறது.

#### படி 5: உங்கள் PR-ஐச் சமர்ப்பிக்கவும் {#step-5}

`dev` கிளைக்கு உங்கள் மாற்றங்களுடன் ஒரு இழுப்பு கோரிக்கையைத் திறக்கவும். குழு உங்கள் சமர்ப்பிப்பை மதிப்பாய்வு செய்து கருத்துக்களை வழங்கும்.

## பராமரிப்பு {#maintenance}

பட்டியலிடப்பட்ட காணொளிகள் இவற்றை உறுதிசெய்ய வழக்கமாக மதிப்பாய்வு செய்யப்படுகின்றன:

- இன்னும் பட்டியலிடல் அளவுகோல்களைப் பூர்த்தி செய்கின்றனவா
- துல்லியமான, புதுப்பித்த தகவல்களைக் கொண்டுள்ளனவா
- வேலை செய்யும் ஹோஸ்டிங்/யூடியூப் இணைப்புகளைக் கொண்டுள்ளனவா
