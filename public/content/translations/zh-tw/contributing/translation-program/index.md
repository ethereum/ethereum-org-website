翻譯計畫是一項協作工作，旨在將 ethereum.org 翻譯成不同的語言，讓全球數十億非英語母語人士更容易使用該網站。

![](./enterprise-eth.png)

## 計畫狀態 {#program-status}

ethereum.org 翻譯計畫即將結束，不再為新譯者提供入門引導。Crowdin 專案即將關閉，我們不再透過該專案接受新的翻譯提交。

我們非常感謝數千名社群譯者多年來將 ethereum.org 翻譯成數十種語言——他們的作品將繼續保留在網站上，並且在[致謝](/contributing/translation-program/acknowledgements/)和[貢獻者](/contributing/translation-program/contributors/)頁面上的表彰也會保留。

如果您在現有翻譯中發現錯誤，請[在 GitHub 上開啟 issue](https://github.com/ethereum/ethereum-org-website/issues/new/choose)。

_加入 [ethereum.org Discord](https://discord.gg/ethereum-org) 提問或分享回饋。_

## 關於翻譯計畫 {#about-us}

[以太坊](/)社群致力於實現全球化和包容性，但其大部分內容僅迎合英語母語人士，將全球 60 億非英語母語人士排除在外。為了讓 ethereum.org 成為全球社群進入以太坊的入口網站，我們認為以非英語母語人士的母語提供以太坊內容是不可或缺的。

ethereum.org 翻譯計畫旨在透過將 ethereum.org 和其他以太坊內容翻譯成盡可能多的語言，讓每個人都能接觸到以太坊。

### 致謝 {#acknowledgements}

Ethereum.org 已由數千名社群成員翻譯，他們是翻譯計畫的關鍵部分。
我們希望表彰我們的譯者，並在他們的職涯道路上提供支援。以下是我們對譯者的一些致謝方式：

#### 證書 {#certificate}

如果您曾為翻譯計畫做出貢獻，且至少有 5,000 個翻譯字數獲得核准，您就有資格獲得 ethereum.org 譯者證書。[了解更多關於證書的資訊](/contributing/translation-program/acknowledgements/#certificate)

#### OAT {#oats}

翻譯計畫的貢獻者有資格根據其 2024 年的翻譯字數獲得不同的 OAT（鏈上成就代幣）。OAT 是證明您對 ethereum.org 翻譯計畫貢獻的 NFT。[了解更多關於 OAT 的資訊](/contributing/translation-program/acknowledgements/#oats)

#### 譯者致謝 {#translator-acknowledgements}

透過[排行榜](/contributing/translation-program/acknowledgements/)和[翻譯計畫所有貢獻者名單](/contributing/translation-program/contributors/)公開表彰我們的頂尖譯者。

#### 獎勵 {#rewards}

過去，我們曾追溯獎勵最活躍的貢獻者，提供他們參加 [Devcon](https://devcon.org/en/) 和 [Devconnect](https://devconnect.org/) 等以太坊研討會的門票，以及專屬的 ethereum.org 周邊商品。

## 聯絡我們 {#get-in-touch}

您有任何問題嗎？或者想與我們的團隊和其他譯者合作？請在我們的 [ethereum.org Discord 伺服器](https://discord.gg/ethereum-org)的 #translations 頻道中發文。

您也可以透過 translations@ethereum.org 聯絡我們。

## 啟動您自己的翻譯計畫 {#starting-a-translation-program}

讓每個人都能取得教育內容仍然是 ethereum.org 的首要任務，我們希望協助其他以太坊專案組織、管理和改善他們自己的翻譯工作。

基於這個原因，我們建立了一份[翻譯計畫教戰手冊](/contributing/translation-program/playbook/)，其中包含我們在翻譯 ethereum.org 過程中學到的一些提示和最佳實務。

想要進一步合作或使用我們的一些翻譯資源嗎？對教戰手冊有任何回饋嗎？我們非常樂意收到您的來信，請聯絡 translations@ethereum.org。
