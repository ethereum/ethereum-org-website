У Solidity [події](/developers/docs/smart-contracts/anatomy/#events-and-logs) — це відправлені сигнали, які можуть генерувати смарт-контракти. Децентралізовані застосунки (dapps) або будь-що, підключене до API JSON-RPC Етеріуму, може прослуховувати ці події та діяти відповідно. Подія також може бути проіндексована, щоб історію подій можна було шукати пізніше.

## Події {#events}

Однією з найпоширеніших подій у блокчейні Етеріум є подія `Transfer`, яка генерується токенами ERC-20, коли хтось переказує токени.

```solidity
event Transfer(address indexed from, address indexed to, uint256 value);
```

Підпис події оголошується всередині коду контракту і може бути згенерований за допомогою ключового слова emit. Наприклад, подія переказу логує, хто надіслав переказ (_from_), кому (_to_) і скільки токенів було переказано (_value_).

Повернімося до смарт-контракту `Counter` з посібника [розгортання вашого першого смарт-контракту](/developers/tutorials/deploying-your-first-smart-contract/) і будемо логувати кожну зміну значення. Це виглядатиме так:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {

    event ValueChanged(uint256 oldValue, uint256 newValue);

    // Публічна змінна типу unsigned int для зберігання кількості підрахунків
    uint256 public count = 0;

    // Функція, що збільшує наш лічильник
    function increment() public {
        count += 1;
        emit ValueChanged(count - 1, count);
    }

    // Необов'язковий геттер для отримання значення підрахунку
    function getCount() public view returns (uint256) {
        return count;
    }

}
```

Зверніть увагу, що:

- **Рядок 6**: ми оголошуємо нашу подію та те, що вона містить: старе значення та нове значення.

- **Рядок 14**: Коли ми збільшуємо нашу змінну count, ми генеруємо подію.

Якщо ми тепер розгорнемо контракт і викличемо функцію increment, ми побачимо, що Remix автоматично відобразить це, якщо ви натиснете на нову транзакцію всередині масиву з назвою logs.

![Скриншот Remix](./remix-screenshot.png)

Логи дуже корисні для налагодження ваших смарт-контрактів, але вони також важливі, якщо ви створюєте застосунки, якими користуються різні люди, оскільки вони полегшують створення аналітики для відстеження та розуміння того, як використовується ваш смарт-контракт. Логи, згенеровані транзакціями, відображаються в популярних оглядачах блоків, і ви також можете, наприклад, використовувати їх для створення позамережевих скриптів для прослуховування певних подій і виконання дій, коли вони відбуваються.
