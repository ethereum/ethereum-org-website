**Ethereum on Arm — це спеціальний образ Linux, який може перетворити Raspberry Pi на вузол Етеріуму.**

Щоб використовувати Ethereum on Arm для перетворення Raspberry Pi на вузол Етеріуму, рекомендується таке обладнання:

- Raspberry Pi 5 з 16 ГБ оперативної пам'яті
- NVMe HAT для Raspberry Pi 5, щоб підключити NVMe-диск
- NVMe SSD (M.2 2280), мінімум 4 ТБ. Уникайте дисків із контролером Phison, які мають відомі проблеми із сумісністю.
- Картка MicroSD (мінімум 16 ГБ, клас 10)
- Блок живлення
- Кабель Ethernet
- Переадресація портів (додаткову інформацію див. у клієнтах)
- Корпус із радіатором
- USB-клавіатура, монітор та кабель HDMI (micro-HDMI) (необов'язково)

Ethereum on Arm також підтримує інші плати ARM, такі як NanoPC T6, Rock 5B та Orange Pi 5 Plus. Ці плати мають вбудовану підтримку NVMe, тому команда Ethereum on Arm рекомендує їх замість Raspberry Pi 5, якщо ви купуєте нове обладнання. Детальніше див. у [списку рекомендованого обладнання](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/overview/supported-hardware.html). Решта цього посібника однакова для всіх підтримуваних плат, за винятком файлу образу, який ви завантажуєте.

## Чому варто запускати Етеріум на ARM? {#why-run-ethereum-on-arm}

Плати ARM — це дуже доступні, гнучкі та компактні комп'ютери. Вони є чудовим вибором для запуску вузлів Етеріуму, оскільки їх можна придбати за невелику ціну, налаштувати так, щоб усі їхні ресурси були зосереджені лише на вузлі (що робить їх ефективними), вони споживають мало електроенергії та мають невеликі фізичні розміри, тому можуть непомітно розміститися в будь-якому домі. Також дуже легко розгортати вузли, оскільки MicroSD для Raspberry Pi можна просто прошити готовим образом, без необхідності завантажувати або збирати програмне забезпечення.

## Як це працює? {#how-does-it-work}

На карту пам'яті Raspberry Pi записується попередньо зібраний образ. Цей образ містить усе необхідне для запуску вузла Етеріуму. З прошитою картою користувачеві потрібно лише увімкнути Raspberry Pi. Усі процеси, необхідні для роботи вузла, запускаються автоматично. Це працює завдяки тому, що карта пам'яті містить операційну систему (ОС) на базі Linux, поверх якої автоматично запускаються процеси системного рівня, що перетворюють пристрій на вузол Етеріуму.

Образи Ethereum on Arm базуються на 64-бітному дистрибутиві Linux, оптимізованому для запуску вузла Етеріуму, і включають попередньо зібрані клієнти Етеріуму.

**Образи беруть на себе всі необхідні кроки**, від налаштування середовища та форматування NVMe-диска до встановлення програмного забезпечення Етеріуму.

## Примітка щодо клієнтів виконання та консенсусу {#note-on-execution-and-consensus-clients}

Образ Ethereum on Arm включає попередньо зібрані клієнти виконання та консенсусу як служби. Для роботи вузла Етеріуму потрібно, щоб обидва клієнти були синхронізовані та запущені. Вам потрібно лише завантажити та прошити образ, а потім запустити служби. Образ попередньо завантажено кількома клієнтами виконання (такими як Geth, Nethermind, Besu, Erigon та Reth) і клієнтами консенсусу (такими як Lighthouse, Prysm, Teku, Nimbus та Lodestar). Поточний список див. у [документації Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/running-a-node/managing-clients.html).

Вам слід вибрати по одному з кожного для запуску — усі клієнти виконання сумісні з усіма клієнтами консенсусу. У цьому посібнику використовуються Geth та Lighthouse.

## Завантаження образу {#downloading-the-image}

Образ Ethereum on Arm — це образ типу «plug and play», який автоматично встановлює та налаштовує як клієнт виконання, так і клієнт консенсусу, конфігуруючи їх для взаємодії один з одним та підключення до мережі Етеріум. Усе, що потрібно зробити користувачеві, — це запустити їхні процеси за допомогою простої команди.

Завантажте останній образ для вашої плати зі [сторінки завантаження Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/getting-started/installation.html#image-downloads). На сторінці завантаження також вказана контрольна сума SHA-256 кожного образу. Перевірте завантажений файл за її допомогою:

```sh
# З директорії, що містить завантажений образ
sha256sum ethonarm_rpi5_<version>.img.zip
# Порівняйте вивід із контрольною сумою на сторінці завантаження
```

## Прошивка MicroSD {#flashing-the-microsd}

Картку MicroSD, яка буде використовуватися для Raspberry Pi, спочатку слід вставити в настільний комп'ютер або ноутбук, щоб її можна було прошити. Потім наступні команди термінала прошиють завантажений образ на SD-карту:

```shell
# перевірте назву MicroSD-картки
sudo fdisk -l

>> sdxxx
```

Дуже важливо правильно вказати назву, оскільки наступна команда містить `dd`, що повністю стирає наявний вміст карти перед записом на неї образу. Щоб продовжити, перейдіть до каталогу, що містить заархівований образ:

```shell
# розархівуйте та прошийте образ
unzip ethonarm_rpi5_<version>.img.zip
sudo dd bs=1M if=ethonarm_rpi5_<version>.img of=/dev/<sdxx> conv=fdatasync status=progress
```

Тепер карту прошито, тому її можна вставити в Raspberry Pi.

## Запуск вузла {#start-the-node}

Вставивши SD-карту в Raspberry Pi, підключіть кабель Ethernet та NVMe-диск, а потім увімкніть живлення. ОС завантажиться та автоматично почне виконувати попередньо налаштовані завдання, які перетворюють Raspberry Pi на вузол Етеріуму, включаючи форматування NVMe-диска та встановлення клієнтського програмного забезпечення. Це, ймовірно, займе 10–15 хвилин, і плата автоматично перезавантажиться після завершення. Не переривайте живлення протягом цього часу.

Після того, як усе буде встановлено та налаштовано, увійдіть у пристрій через SSH-з'єднання або безпосередньо за допомогою термінала, якщо до плати підключено монітор та клавіатуру. Використовуйте акаунт `ethereum` для входу, оскільки він має дозволи, необхідні для запуску вузла.

```shell
User: ethereum
Password: ethereum
```

Під час першого входу вам буде запропоновано змінити пароль за замовчуванням. Зробіть це, оскільки будь-хто, хто має доступ до вашого вузла, інакше зможе увійти з паролем за замовчуванням. Системний брандмауер вимкнено за замовчуванням, тому, якщо ваш вузол має публічну IP-адресу, перегляньте [посібник із безпеки Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/system/security.html), щоб увімкнути його.

Спочатку запустіть клієнт консенсусу. Відкрийте порт 9000 (TCP та UDP) на вашому маршрутизаторі, щоб Lighthouse міг знаходити піри та підключатися до них. Потім увімкніть і запустіть службу lighthouse, щоб вона також перезапускалася після перезавантаження:

```sh
sudo systemctl enable --now lighthouse-beacon
```

Перевірте клієнт за допомогою логів:

```sh
sudo journalctl -u lighthouse-beacon -f
```

Далі запустіть клієнт виконання. Відкрийте порт 30303 (TCP та UDP) на вашому маршрутизаторі, щоб Geth міг знаходити піри та підключатися до них. Потім увімкніть і запустіть службу geth:

```sh
sudo systemctl enable --now geth
```

Ви можете підтвердити, що він працює, перевіривши логи:

```sh
sudo journalctl -u geth -f
```

Зверніть увагу, що клієнт консенсусу синхронізується за кілька хвилин, оскільки він використовує синхронізацію за контрольною точкою. Клієнту виконання знадобиться більше часу — потенційно кілька годин. Обидва клієнти працюють одночасно: клієнт консенсусу повідомляє клієнту виконання, який блок є вершиною ланцюга, а клієнт виконання завантажує та перевіряє блоки до нього.

Із запущеними та синхронізованими службами Geth та Lighthouse ваш Raspberry Pi тепер є вузлом Етеріуму! Найчастіше взаємодія з мережею Етеріум відбувається за допомогою консолі JavaScript Geth, яку можна підключити до клієнта Geth на порту 8545. Також можна надсилати команди у форматі JSON-об'єктів за допомогою інструмента запитів, такого як Curl. Детальніше див. у [документації Geth](https://geth.ethereum.org/).

Образ також містить інформаційну панель Grafana, яку більш досвідчені користувачі можуть використовувати для моніторингу стану свого вузла, перейшовши за адресою `ipaddress:3000` у браузері.

## Валідатори {#validators}

До клієнта консенсусу також можна додатково додати валідатор. Програмне забезпечення валідатора дозволяє вашому вузлу брати активну участь у консенсусі та забезпечує мережу криптоекономічною безпекою. За цю роботу ви отримуєте винагороду в ETH. Щоб запустити валідатор, ви повинні спочатку мати 32 ETH, які потрібно внести в депозитний контракт. Депозит можна зробити, дотримуючись покрокового посібника на [Launchpad](https://launchpad.ethereum.org/). Зробіть це на настільному комп'ютері/ноутбуці, але не генеруйте ключі — це можна зробити безпосередньо на Raspberry Pi.

Інструмент [ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) генерує ключі валідатора. Поточні образи включають його; якщо ви використовуєте старіший образ, спочатку встановіть його. Потім згенеруйте ключі депозиту, замінивши `<YOUR_ETH_ADDRESS>` на адресу, яка має отримувати ваші зняття:

```sh
sudo apt-get update
sudo apt-get install ethstaker-deposit-cli
cd && deposit new-mnemonic --num_validators 1 --execution_address <YOUR_ETH_ADDRESS> --chain mainnet
```

(Або завантажте [ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) для запуску на ізольованій від мережі машині та виконайте команду `deposit new-mnemonic` там)

Зберігайте мнемонічну фразу в безпеці! Наведена вище команда згенерувала два файли в каталозі `validator_keys`: ключі валідатора та файл даних депозиту. Дані депозиту потрібно завантажити в Launchpad, тому їх слід скопіювати з Raspberry Pi на настільний комп'ютер/ноутбук. Це можна зробити за допомогою SSH-з'єднання або будь-якого іншого методу копіювання/вставлення.

Коли файл даних депозиту буде доступний на комп'ютері, де запущено Launchpad, його можна перетягнути на `+` на екрані Launchpad. Дотримуйтесь інструкцій на екрані, щоб надіслати транзакцію в депозитний контракт.

Повернувшись до Raspberry Pi, можна запустити валідатор. Для цього потрібно імпортувати ключі валідатора, встановити адресу для збору винагород, а потім запустити попередньо налаштований процес валідатора. Наведений нижче приклад стосується Lighthouse — інструкції для інших клієнтів консенсусу доступні в [документації Ethereum on Arm](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/staking/solo-staking.html):

```shell
# імпортуйте ключі валідатора
lighthouse account validator import --directory=/home/ethereum/validator_keys

# встановіть адресу для винагород (замініть <YOUR_ETH_ADDRESS> на вашу адресу)
sudo sed -i 's/changeme/<YOUR_ETH_ADDRESS>/' /etc/ethereum/lighthouse-validator.conf

# запустіть валідатор
sudo systemctl enable --now lighthouse-validator
```

Вітаємо, тепер у вас є повноцінний вузол Етеріуму та валідатор, що працюють на Raspberry Pi!
