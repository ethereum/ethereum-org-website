Solidity में, [घटनाएँ](/developers/docs/smart-contracts/anatomy/#events-and-logs) ऐसे प्रेषित सिग्नल होते हैं जिन्हें स्मार्ट अनुबंध ट्रिगर कर सकते हैं। विकेंद्रीकृत एप्लिकेशन (dapp), या इथेरियम जेसन-आरपीसी API से जुड़ा कुछ भी, इन घटनाओं को सुन सकता है और उसके अनुसार कार्य कर सकता है। किसी घटना को अनुक्रमित (indexed) भी किया जा सकता है ताकि घटना के इतिहास को बाद में खोजा जा सके।

## घटनाएँ {#events}

इथेरियम ब्लॉकचेन पर सबसे आम इवेंट्स में से एक `Transfer` इवेंट है जो ERC-20 टोकन द्वारा तब उत्सर्जित किया जाता है जब कोई टोकन ट्रांसफर करता है।

```solidity
event Transfer(address indexed from, address indexed to, uint256 value);
```

इवेंट हस्ताक्षर को अनुबंध कोड के अंदर घोषित किया जाता है और इसे emit कीवर्ड के साथ उत्सर्जित किया जा सकता है। उदाहरण के लिए, ट्रांसफर इवेंट यह लॉग करता है कि ट्रांसफर किसने भेजा (_from_), किसे भेजा (_to_) और कितने टोकन ट्रांसफर किए गए (_value_)।

आइए [अपना पहला स्मार्ट अनुबंध तैनात करना](/developers/tutorials/deploying-your-first-smart-contract/) से `Counter` स्मार्ट अनुबंध पर वापस चलें और हर बार मान बदलने पर उसे लॉग करें। यह कुछ इस तरह दिखेगा:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {

    event ValueChanged(uint256 oldValue, uint256 newValue);

    // काउंट्स की संख्या रखने के लिए unsigned int प्रकार का पब्लिक वेरिएबल
    uint256 public count = 0;

    // फ़ंक्शन जो हमारे काउंटर को बढ़ाता है
    function increment() public {
        count += 1;
        emit ValueChanged(count - 1, count);
    }

    // काउंट वैल्यू प्राप्त करने के लिए अनावश्यक गेटर
    function getCount() public view returns (uint256) {
        return count;
    }

}
```

ध्यान दें कि:

- **पंक्ति 6**: हम अपने इवेंट की घोषणा करते हैं और यह बताते हैं कि इसमें क्या शामिल है, पुराना मान और नया मान।

- **पंक्ति 14**: जब हम अपने count चर (variable) को बढ़ाते हैं, तो हम इवेंट उत्सर्जित करते हैं।

यदि अब हम अनुबंध को तैनात करते हैं और increment फ़ंक्शन को कॉल करते हैं, तो हम देखेंगे कि यदि आप logs नामक एरे के अंदर नए लेन-देन पर क्लिक करते हैं, तो Remix इसे स्वचालित रूप से प्रदर्शित करेगा।

लॉग आपके स्मार्ट अनुबंधों को डीबग करने के लिए वास्तव में उपयोगी होते हैं, लेकिन यदि आप विभिन्न लोगों द्वारा उपयोग किए जाने वाले एप्लिकेशन बनाते हैं तो वे भी महत्वपूर्ण होते हैं और यह ट्रैक करने और समझने के लिए एनालिटिक्स बनाना आसान बनाते हैं कि आपके स्मार्ट अनुबंध का उपयोग कैसे किया जाता है। लेन-देन द्वारा उत्पन्न लॉग लोकप्रिय ब्लॉक एक्सप्लोरर में प्रदर्शित होते हैं और उदाहरण के लिए आप उनका उपयोग विशिष्ट इवेंट्स को सुनने और उनके घटित होने पर कार्रवाई करने के लिए ऑफचेन स्क्रिप्ट बनाने के लिए भी कर सकते हैं।
