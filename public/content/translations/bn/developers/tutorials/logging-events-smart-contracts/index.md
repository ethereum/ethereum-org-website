Solidity-তে, [ইভেন্ট](/developers/docs/smart-contracts/anatomy/#events-and-logs) হলো প্রেরিত সিগন্যাল যা স্মার্ট কন্ট্রাক্ট ফায়ার করতে পারে। বিকেন্দ্রীকৃত অ্যাপ্লিকেশন (dapp), বা ইথেরিয়াম জেসন-আরপিসি API-এর সাথে সংযুক্ত যেকোনো কিছু, এই ইভেন্টগুলো শুনতে পারে এবং সেই অনুযায়ী কাজ করতে পারে। একটি ইভেন্টকে ইনডেক্সও করা যেতে পারে যাতে ইভেন্টের ইতিহাস পরে অনুসন্ধানযোগ্য হয়।

## ইভেন্ট {#events}

ইথেরিয়াম ব্লকচেইনের অন্যতম সাধারণ ইভেন্ট হলো `Transfer` ইভেন্ট, যা কেউ টোকেন হস্তান্তর করলে ERC-20 টোকেন থেকে নির্গত হয়।

```solidity
event Transfer(address indexed from, address indexed to, uint256 value);
```

ইভেন্ট স্বাক্ষরটি কন্ট্রাক্ট কোডের ভেতরে ঘোষণা করা হয় এবং emit কীওয়ার্ডের মাধ্যমে এমিট করা যেতে পারে। উদাহরণস্বরূপ, হস্তান্তর ইভেন্ট লগ করে কে হস্তান্তর পাঠিয়েছে (_from_), কাকে পাঠিয়েছে (_to_) এবং কতগুলো টোকেন হস্তান্তর করা হয়েছে (_value_)।

চলুন [আপনার প্রথম স্মার্ট কন্ট্রাক্ট ডিপ্লয় করা](/developers/tutorials/deploying-your-first-smart-contract/)-এর `Counter` স্মার্ট কন্ট্রাক্টে ফিরে যাই এবং প্রতিবার মান পরিবর্তন হওয়ার সময় লগ করি। এটি দেখতে এমন হবে:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {

    event ValueChanged(uint256 oldValue, uint256 newValue);

    // গণনার সংখ্যা সংরক্ষণ করার জন্য unsigned int টাইপের পাবলিক ভেরিয়েবল
    uint256 public count = 0;

    // যে ফাংশনটি আমাদের কাউন্টার বৃদ্ধি করে
    function increment() public {
        count += 1;
        emit ValueChanged(count - 1, count);
    }

    // কাউন্টের মান পাওয়ার জন্য অপ্রয়োজনীয় গেটার
    function getCount() public view returns (uint256) {
        return count;
    }

}
```

লক্ষ্য করুন যে:

- **লাইন 6**: আমরা আমাদের ইভেন্ট এবং এতে কী রয়েছে, অর্থাৎ পুরানো মান এবং নতুন মান ঘোষণা করি।

- **লাইন 14**: যখন আমরা আমাদের count ভেরিয়েবল বৃদ্ধি করি, তখন আমরা ইভেন্টটি এমিট করি।

আমরা যদি এখন কন্ট্রাক্টটি ডিপ্লয় করি এবং increment ফাংশনটি কল করি, তবে আমরা দেখতে পাব যে আপনি logs নামের একটি অ্যারের ভেতরে নতুন ট্রানজ্যাকশনে ক্লিক করলে Remix স্বয়ংক্রিয়ভাবে এটি প্রদর্শন করবে।

![Remix স্ক্রিনশট](./remix-screenshot.png)

লগগুলো আপনার স্মার্ট কন্ট্রাক্ট ডিবাগ করার জন্য সত্যিই দরকারী, তবে আপনি যদি বিভিন্ন মানুষের ব্যবহৃত অ্যাপ্লিকেশন তৈরি করেন তবে এগুলো গুরুত্বপূর্ণ এবং আপনার স্মার্ট কন্ট্রাক্ট কীভাবে ব্যবহৃত হচ্ছে তা ট্র্যাক করতে এবং বুঝতে অ্যানালিটিক্স তৈরি করা সহজ করে তোলে। ট্রানজ্যাকশন দ্বারা জেনারেট করা লগগুলো জনপ্রিয় ব্লক এক্সপ্লোরারগুলোতে প্রদর্শিত হয় এবং আপনি উদাহরণস্বরূপ নির্দিষ্ট ইভেন্টগুলো শোনার জন্য এবং সেগুলো ঘটলে ব্যবস্থা নেওয়ার জন্য অফচেইন স্ক্রিপ্ট তৈরি করতেও এগুলো ব্যবহার করতে পারেন।
