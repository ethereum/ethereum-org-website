[<span dir="ltr">ethereum.org</span> کی ویڈیو گیلری](/videos/) میں کمیونٹی کے تخلیق کاروں اور قابل اعتماد ذرائع سے ایتھیریم اور ایتھیریم ایکو سسٹم کے بارے میں ویڈیوز شامل ہیں۔ کوئی بھی شخص ویڈیو شامل کرنے کی تجویز دے سکتا ہے۔

## فہرست سازی کی پالیسی {#listing-policy}

<span dir="ltr">Ethereum.org</span> ایک غیر جانبدار، تعلیمی وسیلہ ہے۔ ویڈیو گیلری کو درج ذیل مقاصد کے لیے ترتیب دیا گیا ہے:

- صارفین کو ایتھیریم ٹیکنالوجی، ایکو سسٹم، اور کمیونٹی کے بارے میں **تعلیم دینا**
- اپنے تکنیکی مواد میں **درست رہنا**
- ایتھیریم کمیونٹی سے **متعلقہ رہنا**

یہ سائٹ ایسی ویڈیوز کو فہرست میں شامل نہیں کرتی جو بنیادی طور پر کسی مخصوص پروڈکٹ، ٹوکن، یا تجارتی سروس کی تشہیر کرتی ہوں۔

## شمولیت کا معیار {#criteria-for-inclusion}

### لازمی شرائط {#must-haves}

- **ایتھیریم پر مرکوز** – ویڈیو بنیادی طور پر ایتھیریم، اس کی ٹیکنالوجی، ایکو سسٹم، یا کمیونٹی کے بارے میں ہونی چاہیے۔ عام بلاک چین موضوعات پر ویڈیوز صرف اسی صورت میں قابل قبول ہیں جب وہ سائٹ کے کسی تعلیمی صفحے کی خاطر خواہ حمایت کرتی ہوں یا اس سے متعلق ہوں، یا ایتھیریم کا حوالہ دیتی ہوں۔
- **تعلیمی اہمیت** – ویڈیو کو ناظرین کو ایتھیریم کے بارے میں کچھ سکھانا چاہیے، یا عالمی ایتھیریم کمیونٹی کو سراہنا چاہیے۔ تشہیری یا مارکیٹنگ کے مواد کو قبول نہیں کیا جائے گا۔
- **درست معلومات** – تکنیکی مواد حقائق پر مبنی اور اپ ٹو ڈیٹ ہونا چاہیے۔ متروک خصوصیات کے بارے میں پرانی ویڈیوز کو ہٹایا جا سکتا ہے۔
- **معیاری پروڈکشن** – ویڈیو کی آڈیو اور ویڈیو کوالٹی معقول حد تک واضح ہونی چاہیے۔
- **عوامی طور پر دستیاب** – ویڈیو کو کسی کھلے وسیلے یا قابل رسائی پلیٹ فارم جیسے یوٹیوب پر ہوسٹ کیا جانا چاہیے، اور پے وال یا سائن اپ کی ضرورت کے بغیر آزادانہ طور پر قابل رسائی ہونا چاہیے۔

### مستحسن شرائط {#nice-to-haves}

- **ٹرانسکرپٹ کا ہونا** – ٹرانسکرپٹ والی ویڈیوز رسائی اور <span dir="ltr">SEO</span> کو بہتر بناتی ہیں۔ اگر آپ کے پاس یہ نہیں ہے، تو <span dir="ltr">ethereum.org</span> کی ٹیم اسے تیار کرنے میں مدد کر سکتی ہے۔
- **قابل اعتماد ذریعہ سے** – مستند ماہرین تعلیم، محققین، اور ذرائع کے مواد کو ترجیح دی جاتی ہے۔
- **بروقت اور سدا بہار** – ایسا مواد جو وقت گزرنے کے ساتھ متعلقہ رہے، اسے وقت کے لحاظ سے حساس مواد پر ترجیح دی جاتی ہے۔

## ویڈیو شامل کرنے کا طریقہ {#how-to-add-a-video}

### آپشن 1: ایک ایشو کھولیں {#open-an-issue}

اگر آپ کوئی ویڈیو تجویز کرنا چاہتے ہیں لیکن خود فائلیں نہیں بنانا چاہتے، تو ویڈیو کی تفصیلات کے ساتھ ایک <span dir="ltr">GitHub</span> ایشو کھولیں اور کوئی معاون اسے آپ کے لیے شامل کرنے میں مدد کر سکتا ہے۔

<ButtonLink href="https://github.com/ethereum/ethereum-org-website/issues/new?template=suggest_video.yaml">
  ویڈیو تجویز کریں
</ButtonLink>

### آپشن 2: پل ریکوئسٹ کھولیں {#open-a-pull-request}

اگر آپ خود ویڈیو شامل کرنا چاہتے ہیں، تو ان اقدامات پر عمل کریں:

#### مرحلہ 1: ویڈیو فائل بنائیں {#step-1}

ایک نئی ڈائریکٹری اور `index.md` فائل یہاں بنائیں:

```
public/content/videos/{your-video-slug}/index.md
```

سلگ <span dir="ltr">URL</span> کے لیے محفوظ، چھوٹے حروف (lowercase) میں، اور ہائفن کے ساتھ ہونا چاہیے (جیسے، `blockchain-101-visual-demo`)۔

#### مرحلہ 2: فرنٹ میٹر شامل کریں {#step-2}

اپنی `index.md` میں درج ذیل <span dir="ltr">YAML</span> فرنٹ میٹر شامل کریں:

```yaml
---
title: "Your Video Title"
description: "A brief 1–3 sentence summary of the video."
lang: en
youtubeId: "dQw4w9WgXcQ"
uploadDate: 2025-01-15
duration: "12:30"
educationLevel: beginner
topic:
  - "your-topic"
  - "another-topic"
format: explainer
author: Channel Name
---
```

**فیلڈ کا حوالہ:**

| فیلڈ | لازمی | تفصیل |
|---|---|---|
| `title` | ہاں | ویڈیو کا عنوان |
| `description` | ہاں | <span dir="ltr">1–3</span> جملوں کا خلاصہ |
| `lang` | ہاں | فی الحال ہمیشہ `en` |
| `youtubeId` | ہاں | یوٹیوب ویڈیو کی <span dir="ltr">ID</span> (<span dir="ltr">URL</span> میں `v=` کے بعد) |
| `uploadDate` | ہاں | اپ لوڈ کی اصل تاریخ `YYYY-MM-DD` فارمیٹ میں |
| `duration` | ہاں | ویڈیو کا دورانیہ `H:MM:SS` یا `M:SS` کے طور پر |
| `educationLevel` | ہاں | `beginner`، `intermediate`، یا `advanced` |
| `topic` | ہاں | گیلری فلٹرنگ کے لیے ٹاپک ٹیگز کی ارے (Array) |
| `format` | ہاں | `explainer`، `presentation`، `interview`، `tutorial`، یا `panel` |
| `author` | ہاں | تخلیق کار یا چینل کا نام |
| `breadcrumb` | نہیں | بریڈکرمب نیویگیشن کے لیے کسٹم مختصر لیبل |
| `customThumbnailUrl` | نہیں | کسٹم تھمب نیل <span dir="ltr">URL</span> (پہلے سے طے شدہ یوٹیوب تھمب نیل ہوتا ہے) |

#### مرحلہ 3: ٹرانسکرپٹ شامل کریں (تجویز کردہ) {#step-3}

فرنٹ میٹر `---` کے نیچے، مارک ڈاؤن فارمیٹ میں ویڈیو کا ٹرانسکرپٹ شامل کریں:

```markdown
---
title: "..."
# ... باقی فرنٹ میٹر
---

ویڈیو کے مواد کا ایک مختصر تعارف۔

### سیکشن کا عنوان (0:00)

اس سیکشن کے لیے ٹرانسکرپٹ کا متن...

### اگلا سیکشن (5:30)

مزید ٹرانسکرپٹ کا متن...
```

اہم سیکشنز کو نشان زد کرنے کے لیے ٹائم اسٹامپس کے ساتھ `###` ہیڈنگز کا استعمال کریں۔ یہ ٹرانسکرپٹ کو پڑھنے میں آسان بناتا ہے اور <span dir="ltr">SEO</span> کو بہتر کرتا ہے۔

اگر آپ کے پاس ٹرانسکرپٹ نہیں ہے، تو آپ باڈی کو خالی چھوڑ سکتے ہیں اور ٹیم اسے تیار کر لے گی۔

#### مرحلہ 4: ٹاپک ٹیگز کا انتخاب کریں {#step-4}

ذیل کی فہرست سے ٹاپک ٹیگز منتخب کریں۔ ہر ٹیگ براہ راست ویڈیو گیلری میں ایک فلٹر کیٹیگری سے منسلک ہوتا ہے — ٹیگ کا نام بالکل ویسے ہی استعمال کریں جیسا دکھایا گیا ہے۔

ایک ویڈیو میں متعدد گیلری فلٹرز میں ظاہر ہونے کے لیے ایک سے زیادہ ٹیگز ہو سکتے ہیں:

| ٹیگ | گیلری فلٹر |
|---|---|
| `how-ethereum-works` | ایتھیریم کیسے کام کرتا ہے |
| `network-upgrades` | نیٹ ورک اپ گریڈز |
| `roadmap-and-priorities` | روڈ میپ اور ترجیحات |
| `scaling-and-layer-2` | اسکیلنگ اور لیئر ۲ (l2) |
| `use-cases` | استعمال کے کیسز |
| `privacy` | رازداری |
| `security` | سیکیورٹی |
| `community-stories` | کمیونٹی کی کہانیاں |
| `events` | ایونٹس |

ہر ویڈیو میں اس فہرست سے کم از کم ایک ٹیگ ہونا چاہیے۔ بغیر کسی تسلیم شدہ ٹیگ والی ویڈیوز صرف "تمام" (All) ویو اور تلاش کے نتائج میں ظاہر ہوں گی۔

`community-stories` ٹیگ کی وجہ سے ویڈیو [اسٹوریز کے صفحے](/stories/) پر بھی ظاہر ہوتی ہے۔

#### مرحلہ 5: اپنی PR جمع کرائیں {#step-5}

اپنی تبدیلیوں کے ساتھ `dev` برانچ میں ایک پل ریکوئسٹ کھولیں۔ ٹیم آپ کی جمع کرائی گئی تفصیلات کا جائزہ لے گی اور فیڈ بیک فراہم کرے گی۔

## دیکھ بھال {#maintenance}

فہرست میں شامل ویڈیوز کا باقاعدگی سے جائزہ لیا جاتا ہے تاکہ یہ یقینی بنایا جا سکے کہ وہ:

- اب بھی فہرست سازی کے معیار پر پورا اترتی ہیں
- درست اور اپ ٹو ڈیٹ معلومات پر مشتمل ہیں
- ان کے ہوسٹنگ/یوٹیوب لنکس کام کر رہے ہیں

اگر آپ کو فہرست میں شامل کسی ویڈیو میں کوئی مسئلہ نظر آتا ہے، تو [ایک ایشو بنائیں](https://github.com/ethereum/ethereum-org-website/issues/new?assignees=&labels=feature+✨,content+🖋️&template=suggest_video.yaml) یا [<span dir="ltr">website@ethereum.org</span>](mailto:website@ethereum.org) پر ای میل بھیجیں۔
