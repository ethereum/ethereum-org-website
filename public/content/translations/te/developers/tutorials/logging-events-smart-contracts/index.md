Solidity లో, [ఈవెంట్‌లు](/developers/docs/smart-contracts/anatomy/#events-and-logs) అనేవి స్మార్ట్ కాంట్రాక్ట్‌లు ఫైర్ చేయగల డిస్పాచ్ చేయబడిన సిగ్నల్స్. వికేంద్రీకృత అప్లికేషన్‌లు (dapps), లేదా ఎథీరియం జేసన్-ఆర్‌పీసీ API కి కనెక్ట్ చేయబడిన ఏదైనా సరే, ఈ ఈవెంట్‌లను వినగలవు మరియు తదనుగుణంగా వ్యవహరించగలవు. ఈవెంట్ చరిత్రను తర్వాత వెతకడానికి వీలుగా ఒక ఈవెంట్‌ను ఇండెక్స్ కూడా చేయవచ్చు.

## ఈవెంట్‌లు {#events}

ఎథీరియం బ్లాక్‌చైన్‌లో అత్యంత సాధారణ ఘటనలలో ఒకటి `Transfer` ఘటన, ఎవరైనా టోకెన్‌లను బదిలీ చేసినప్పుడు ERC-20 టోకెన్‌ల ద్వారా ఇది ఎమిట్ చేయబడుతుంది.

```solidity
event Transfer(address indexed from, address indexed to, uint256 value);
```

ఘటన సంతకం కాంట్రాక్ట్ కోడ్ లోపల డిక్లేర్ చేయబడుతుంది మరియు emit కీవర్డ్‌తో ఎమిట్ చేయబడుతుంది. ఉదాహరణకు, బదిలీ ఘటన బదిలీని ఎవరు పంపారు (_from_), ఎవరికి పంపారు (_to_) మరియు ఎన్ని టోకెన్‌లు బదిలీ చేయబడ్డాయి (_value_) అనేవి లాగ్ చేస్తుంది.

[మీ మొదటి స్మార్ట్ కాంట్రాక్ట్‌ను డిప్లాయ్ చేయడం](/developers/tutorials/deploying-your-first-smart-contract/) నుండి `Counter` స్మార్ట్ కాంట్రాక్ట్‌కి తిరిగి వెళ్దాం మరియు విలువ మారిన ప్రతిసారీ లాగ్ చేద్దాం. ఇది ఈ విధంగా కనిపిస్తుంది:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {

    event ValueChanged(uint256 oldValue, uint256 newValue);

    // కౌంట్ల సంఖ్యను ఉంచడానికి అన్‌సైన్డ్ ఇంట్ (unsigned int) రకానికి చెందిన పబ్లిక్ వేరియబుల్
    uint256 public count = 0;

    // మన కౌంటర్‌ను పెంచే ఫంక్షన్
    function increment() public {
        count += 1;
        emit ValueChanged(count - 1, count);
    }

    // కౌంట్ విలువను పొందడానికి అవసరం లేని గెట్టర్
    function getCount() public view returns (uint256) {
        return count;
    }

}
```

గమనించండి:

- **లైన్ 6**: మేము మా ఘటనను మరియు అది కలిగి ఉన్న పాత విలువ మరియు కొత్త విలువను డిక్లేర్ చేస్తాము.

- **లైన్ 14**: మేము మా కౌంట్ వేరియబుల్‌ను పెంచినప్పుడు, మేము ఘటనను ఎమిట్ చేస్తాము.

ఇప్పుడు మనం కాంట్రాక్ట్‌ను డిప్లాయ్ చేసి, ఇంక్రిమెంట్ ఫంక్షన్‌ను కాల్ చేస్తే, లాగ్‌లు అనే అర్రే లోపల కొత్త లావాదేవీపై క్లిక్ చేస్తే Remix దాన్ని ఆటోమేటిక్‌గా ప్రదర్శిస్తుందని మనం చూస్తాము.

మీ స్మార్ట్ కాంట్రాక్ట్‌లను డీబగ్ చేయడానికి లాగ్‌లు నిజంగా ఉపయోగకరంగా ఉంటాయి, అయితే మీరు వేర్వేరు వ్యక్తులు ఉపయోగించే అప్లికేషన్‌లను నిర్మిస్తే అవి కూడా ముఖ్యమైనవి మరియు మీ స్మార్ట్ కాంట్రాక్ట్ ఎలా ఉపయోగించబడుతుందో ట్రాక్ చేయడానికి మరియు అర్థం చేసుకోవడానికి విశ్లేషణలను సులభతరం చేస్తాయి. లావాదేవీల ద్వారా రూపొందించబడిన లాగ్‌లు ప్రసిద్ధ బ్లాక్ ఎక్స్‌ప్లోరర్‌లలో ప్రదర్శించబడతాయి మరియు ఉదాహరణకు నిర్దిష్ట ఘటనలను వినడానికి మరియు అవి సంభవించినప్పుడు చర్య తీసుకోవడానికి ఆఫ్‌చైన్ స్క్రిప్ట్‌లను సృష్టించడానికి కూడా మీరు వాటిని ఉపయోగించవచ్చు.
