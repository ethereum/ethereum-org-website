**Ethereum on Arm ही एक कस्टम Linux इमेज आहे जी Raspberry Pi ला इथेरियम नोडमध्ये बदलू शकते.**

Raspberry Pi ला इथेरियम नोडमध्ये बदलण्यासाठी Ethereum on Arm वापरण्याकरिता, खालील हार्डवेअरची शिफारस केली जाते:

- 16 GB RAM सह Raspberry Pi 5
- NVMe डिस्क कनेक्ट करण्यासाठी, Raspberry Pi 5 करिता NVMe HAT
- NVMe SSD (M.2 2280), किमान 4 TB. Phison कंट्रोलर असलेल्या डिस्क्स टाळा, ज्यांच्यामध्ये सुसंगततेच्या ज्ञात समस्या आहेत.
- MicroSD कार्ड (किमान 16 GB Class 10)
- वीज पुरवठा (Power supply)
- इथरनेट केबल
- पोर्ट फॉरवर्डिंग (अधिक माहितीसाठी क्लायंट्स पहा)
- हीटसिंकसह केस
- USB कीबोर्ड, मॉनिटर आणि HDMI केबल (micro-HDMI) (पर्यायी)

Ethereum on Arm इतर ARM बोर्ड्सना देखील सपोर्ट करते, जसे की NanoPC T6, Rock 5B, आणि Orange Pi 5 Plus. या बोर्ड्समध्ये मूळ NVMe सपोर्ट आहे, त्यामुळे जर तुम्ही नवीन हार्डवेअर खरेदी करत असाल तर Ethereum on Arm टीम Raspberry Pi 5 ऐवजी त्यांची शिफारस करते. तपशीलांसाठी [शिफारस केलेली हार्डवेअर सूची](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/overview/supported-hardware.html) पहा. तुम्ही डाउनलोड करत असलेली इमेज फाईल वगळता, या ट्युटोरिअलचा उर्वरित भाग सर्व सपोर्टेड बोर्ड्ससाठी समान आहे.

## ARM वर इथेरियम का चालवावे? {#why-run-ethereum-on-arm}

ARM बोर्ड हे अतिशय परवडणारे, लवचिक आणि छोटे संगणक आहेत. इथेरियम नोड्स चालवण्यासाठी ते उत्तम पर्याय आहेत कारण ते स्वस्तात विकत घेता येतात, त्यांचे सर्व संसाधने फक्त नोडवर केंद्रित करण्यासाठी कॉन्फिगर केले जाऊ शकतात, ज्यामुळे ते कार्यक्षम बनतात, ते कमी प्रमाणात वीज वापरतात आणि शारीरिकदृष्ट्या लहान असल्यामुळे ते कोणत्याही घरात सहजपणे बसू शकतात. नोड्स सुरू करणे देखील खूप सोपे आहे कारण Raspberry Pi चे MicroSD फक्त पूर्व-निर्मित (prebuilt) इमेजसह फ्लॅश केले जाऊ शकते, ज्यासाठी कोणतेही सॉफ्टवेअर डाउनलोड किंवा तयार करण्याची आवश्यकता नसते.

## हे कसे काम करते? {#how-does-it-work}

Raspberry Pi चे मेमरी कार्ड प्रीबिल्ट इमेजसह फ्लॅश केले जाते. या इमेजमध्ये इथेरियम नोड चालवण्यासाठी आवश्यक असलेले सर्व काही असते. फ्लॅश केलेल्या कार्डसह, वापरकर्त्याला फक्त Raspberry Pi चालू करणे आवश्यक आहे. नोड चालवण्यासाठी आवश्यक असलेल्या सर्व प्रक्रिया आपोआप सुरू होतात. हे काम करते कारण मेमरी कार्डमध्ये Linux-आधारित ऑपरेटिंग सिस्टीम (OS) असते ज्यावर सिस्टीम-स्तरीय प्रक्रिया आपोआप चालवल्या जातात ज्या युनिटला इथेरियम नोडमध्ये बदलतात.

Ethereum on Arm इमेजेस 64-बिट Linux डिस्ट्रिब्युशनवर आधारित आहेत जे इथेरियम नोड चालवण्यासाठी ऑप्टिमाइझ केलेले आहेत, आणि त्यामध्ये प्रीबिल्ट इथेरियम क्लायंट्स समाविष्ट आहेत.

**इमेजेस सर्व आवश्यक पायऱ्यांची काळजी घेतात**, वातावरण सेट करण्यापासून आणि NVMe डिस्क फॉरमॅट करण्यापासून ते इथेरियम सॉफ्टवेअर इन्स्टॉल करण्यापर्यंत.

## अंमलबजावणी आणि सहमती क्लायंट्सवरील नोंद {#note-on-execution-and-consensus-clients}

Ethereum on Arm इमेजमध्ये सेवा म्हणून प्रीबिल्ट अंमलबजावणी आणि सहमती क्लायंट्स समाविष्ट आहेत. इथेरियम नोडसाठी दोन्ही क्लायंट्स समक्रमित (synced) आणि चालू असणे आवश्यक आहे. तुम्हाला फक्त इमेज डाउनलोड आणि फ्लॅश करणे आणि नंतर सेवा सुरू करणे आवश्यक आहे. इमेजमध्ये अनेक अंमलबजावणी क्लायंट्स (जसे की Geth, Nethermind, Besu, Erigon, आणि Reth) आणि सहमती क्लायंट्स (जसे की Lighthouse, Prysm, Teku, Nimbus, आणि Lodestar) प्रीलोड केलेले आहेत. सध्याच्या सूचीसाठी [Ethereum on Arm दस्तऐवजीकरण](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/running-a-node/managing-clients.html) पहा.

तुम्ही चालवण्यासाठी प्रत्येकी एक निवडला पाहिजे - सर्व अंमलबजावणी क्लायंट्स सर्व सहमती क्लायंट्सशी सुसंगत आहेत. हे ट्युटोरिअल Geth आणि Lighthouse वापरते.

## इमेज डाउनलोड करणे {#downloading-the-image}

Ethereum on Arm इमेज ही एक "प्लग अँड प्ले" इमेज आहे जी आपोआप अंमलबजावणी आणि सहमती क्लायंट्स दोन्ही इन्स्टॉल आणि सेट करते, त्यांना एकमेकांशी बोलण्यासाठी आणि इथेरियम नेटवर्कशी कनेक्ट करण्यासाठी कॉन्फिगर करते. वापरकर्त्याला फक्त एका साध्या कमांडचा वापर करून त्यांच्या प्रक्रिया सुरू करणे आवश्यक आहे.

[Ethereum on Arm डाउनलोड पृष्ठावरून](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/getting-started/installation.html#image-downloads) तुमच्या बोर्डसाठी नवीनतम इमेज डाउनलोड करा. डाउनलोड पृष्ठ प्रत्येक इमेजचा SHA256 चेकसम देखील सूचीबद्ध करते. डाउनलोड केलेल्या फाईलची त्याच्याशी पडताळणी करा:

```sh
# डाउनलोड केलेली इमेज असलेल्या डिरेक्टरीमधून
sha256sum ethonarm_rpi5_<version>.img.zip
# डाउनलोड पेजवरील चेकसमसोबत आउटपुटची तुलना करा
```

## MicroSD फ्लॅश करणे {#flashing-the-microsd}

Raspberry Pi साठी वापरले जाणारे MicroSD कार्ड प्रथम डेस्कटॉप किंवा लॅपटॉपमध्ये घातले पाहिजे जेणेकरून ते फ्लॅश केले जाऊ शकेल. त्यानंतर, खालील टर्मिनल कमांड्स डाउनलोड केलेली इमेज SD कार्डवर फ्लॅश करतील:

```shell
# MicroSD कार्डचे नाव तपासा
sudo fdisk -l

>> sdxxx
```

नाव योग्य असणे खरोखर महत्त्वाचे आहे कारण पुढील कमांडमध्ये `dd` समाविष्ट आहे जे इमेज कार्डवर ढकलण्यापूर्वी कार्डवरील विद्यमान सामग्री पूर्णपणे पुसून टाकते. सुरू ठेवण्यासाठी, झिप केलेली इमेज असलेल्या डिरेक्टरीवर नेव्हिगेट करा:

```shell
# इमेज अनझिप आणि फ्लॅश करा
unzip ethonarm_rpi5_<version>.img.zip
sudo dd bs=1M if=ethonarm_rpi5_<version>.img of=/dev/<sdxx> conv=fdatasync status=progress
```

कार्ड आता फ्लॅश झाले आहे, त्यामुळे ते Raspberry Pi मध्ये घातले जाऊ शकते.

## नोड सुरू करा {#start-the-node}

Raspberry Pi मध्ये SD कार्ड घातल्यानंतर, इथरनेट केबल आणि NVMe डिस्क कनेक्ट करा आणि नंतर पॉवर चालू करा. OS बूट होईल आणि आपोआप पूर्व-कॉन्फिगर केलेली कार्ये करण्यास सुरुवात करेल जी Raspberry Pi ला इथेरियम नोडमध्ये बदलतात, ज्यामध्ये NVMe डिस्क फॉरमॅट करणे आणि क्लायंट सॉफ्टवेअर इन्स्टॉल करणे समाविष्ट आहे. यास कदाचित 10-15 मिनिटे लागतील, आणि ते पूर्ण झाल्यावर बोर्ड आपोआप रीबूट होईल. या काळात वीज पुरवठ्यात व्यत्यय आणू नका.

एकदा सर्वकाही इन्स्टॉल आणि कॉन्फिगर झाल्यानंतर, ssh कनेक्शनद्वारे किंवा बोर्डला मॉनिटर आणि कीबोर्ड जोडलेला असल्यास थेट टर्मिनल वापरून डिव्हाइसमध्ये लॉग इन करा. लॉग इन करण्यासाठी `ethereum` खाते वापरा, कारण यामध्ये नोड सुरू करण्यासाठी आवश्यक परवानग्या आहेत.

```shell
User: ethereum
Password: ethereum
```

तुमच्या पहिल्या लॉगिनवर तुम्हाला डीफॉल्ट पासवर्ड बदलण्यास सांगितले जाईल. ते करा, कारण अन्यथा तुमच्या नोडपर्यंत पोहोचू शकणारी कोणतीही व्यक्ती डीफॉल्ट पासवर्डसह लॉग इन करू शकते. सिस्टीम फायरवॉल डीफॉल्टनुसार अक्षम (disabled) असते, त्यामुळे जर तुमच्या नोडचा सार्वजनिक IP पत्ता असेल, तर ते सक्षम करण्यासाठी [Ethereum on Arm सुरक्षा मार्गदर्शक](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/system/security.html) पहा.

प्रथम सहमती क्लायंट सुरू करा. तुमच्या राउटरवर पोर्ट 9000 (TCP आणि UDP) उघडा जेणेकरून Lighthouse पीअर्स शोधू शकेल आणि त्यांच्याशी कनेक्ट होऊ शकेल. नंतर lighthouse सेवा सक्षम करा आणि सुरू करा, जेणेकरून ती रीबूटनंतर देखील रीस्टार्ट होईल:

```sh
sudo systemctl enable --now lighthouse-beacon
```

नोंदी (logs) वापरून क्लायंट तपासा:

```sh
sudo journalctl -u lighthouse-beacon -f
```

पुढे, अंमलबजावणी क्लायंट सुरू करा. तुमच्या राउटरवर पोर्ट 30303 (TCP आणि UDP) उघडा जेणेकरून Geth पीअर्स शोधू शकेल आणि त्यांच्याशी कनेक्ट होऊ शकेल. नंतर geth सेवा सक्षम करा आणि सुरू करा:

```sh
sudo systemctl enable --now geth
```

तुम्ही नोंदी तपासून ते चालू असल्याची पुष्टी करू शकता:

```sh
sudo journalctl -u geth -f
```

लक्षात घ्या की सहमती क्लायंट काही मिनिटांत समक्रमण (sync) करेल कारण तो चेकपॉईंट समक्रमण वापरतो. अंमलबजावणी क्लायंटला जास्त वेळ लागेल - संभाव्यतः अनेक तास. दोन्ही क्लायंट्स एकाच वेळी चालतात: सहमती क्लायंट अंमलबजावणी क्लायंटला सांगतो की कोणता ब्लॉक चेनचा हेड आहे, आणि अंमलबजावणी क्लायंट तिथपर्यंतचे ब्लॉक्स डाउनलोड करतो आणि त्यांची पडताळणी करतो.

Geth आणि Lighthouse सेवा चालू आणि समक्रमित (synced) असल्याने, तुमचा Raspberry Pi आता एक इथेरियम नोड आहे! Geth च्या JavaScript कन्सोलचा वापर करून इथेरियम नेटवर्कशी संवाद साधणे सर्वात सामान्य आहे, जे पोर्ट 8545 वर Geth क्लायंटला जोडले जाऊ शकते. Curl सारख्या विनंती टूलचा वापर करून JSON ऑब्जेक्ट्स म्हणून फॉरमॅट केलेल्या कमांड्स सबमिट करणे देखील शक्य आहे. [Geth दस्तऐवजीकरणामध्ये](https://geth.ethereum.org/) अधिक पहा.

इमेजमध्ये एक Grafana डॅशबोर्ड देखील समाविष्ट आहे जो अधिक प्रगत वापरकर्ते ब्राउझरमध्ये `ipaddress:3000` वर नेव्हिगेट करून त्यांच्या नोडच्या आरोग्यावर लक्ष ठेवण्यासाठी वापरू शकतात.

## प्रमाणक {#validators}

सहमती क्लायंटमध्ये पर्यायीरित्या एक प्रमाणक देखील जोडला जाऊ शकतो. प्रमाणक सॉफ्टवेअर तुमच्या नोडला एकमतामध्ये (consensus) सक्रियपणे सहभागी होण्याची परवानगी देते आणि नेटवर्कला क्रिप्टोइकॉनॉमिक सुरक्षा प्रदान करते. या कामासाठी तुम्हाला ETH मध्ये बक्षीस मिळते. प्रमाणक चालवण्यासाठी, तुमच्याकडे प्रथम 32 ETH असणे आवश्यक आहे, जे ठेव करारामध्ये (deposit contract) जमा केले जाणे आवश्यक आहे. [लॉन्चपॅडवरील](https://launchpad.ethereum.org/) टप्प्याटप्प्याने मार्गदर्शकाचे अनुसरण करून ठेव (deposit) केली जाऊ शकते. हे डेस्कटॉप/लॅपटॉपवर करा, परंतु कीज (keys) जनरेट करू नका — हे थेट Raspberry Pi वर केले जाऊ शकते.

[ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) टूल प्रमाणक कीज जनरेट करते. सध्याच्या इमेजेसमध्ये ते समाविष्ट आहे; जर तुम्ही जुनी इमेज चालवत असाल, तर ती प्रथम इन्स्टॉल करा. नंतर ठेव कीज जनरेट करा, `<YOUR_ETH_ADDRESS>` ला त्या पत्त्यासह बदलून ज्यावर तुमचे पैसे काढले (withdrawals) जावेत:

```sh
sudo apt-get update
sudo apt-get install ethstaker-deposit-cli
cd && deposit new-mnemonic --num_validators 1 --execution_address <YOUR_ETH_ADDRESS> --chain mainnet
```

(किंवा एअरगॅप्ड मशीनवर चालवण्यासाठी [ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) डाउनलोड करा, आणि तिथे `deposit new-mnemonic` कमांड चालवा)

निमोनिक (mnemonic) वाक्प्रचार सुरक्षित ठेवा! वरील कमांडने `validator_keys` डिरेक्टरीमध्ये दोन फाईल्स जनरेट केल्या: प्रमाणक कीज आणि एक ठेव डेटा फाईल. ठेव डेटा लॉन्चपॅडमध्ये अपलोड करणे आवश्यक आहे, त्यामुळे तो Raspberry Pi वरून डेस्कटॉप/लॅपटॉपवर कॉपी केला जाणे आवश्यक आहे. हे ssh कनेक्शन किंवा इतर कोणत्याही कॉपी/पेस्ट पद्धतीचा वापर करून केले जाऊ शकते.

एकदा ठेव डेटा फाईल लॉन्चपॅड चालवणाऱ्या संगणकावर उपलब्ध झाली की, ती लॉन्चपॅड स्क्रीनवरील `+` वर ड्रॅग आणि ड्रॉप केली जाऊ शकते. ठेव करारावर व्यवहार पाठवण्यासाठी स्क्रीनवरील सूचनांचे अनुसरण करा.

परत Raspberry Pi वर, एक प्रमाणक सुरू केला जाऊ शकतो. यासाठी प्रमाणक कीज आयात करणे, बक्षिसे गोळा करण्यासाठी पत्ता सेट करणे, आणि नंतर पूर्व-कॉन्फिगर केलेली प्रमाणक प्रक्रिया सुरू करणे आवश्यक आहे. खालील उदाहरण Lighthouse साठी आहे—इतर सहमती क्लायंट्ससाठी सूचना [Ethereum on Arm दस्तऐवजांवर](https://ethereum-on-arm-documentation.readthedocs.io/en/latest/staking/solo-staking.html) उपलब्ध आहेत:

```shell
# प्रमाणक कीज आयात करा
lighthouse account validator import --directory=/home/ethereum/validator_keys

# रिवॉर्ड पत्ता सेट करा (<YOUR_ETH_ADDRESS> च्या जागी तुमचा पत्ता टाका)
sudo sed -i 's/changeme/<YOUR_ETH_ADDRESS>/' /etc/ethereum/lighthouse-validator.conf

# प्रमाणक सुरू करा
sudo systemctl enable --now lighthouse-validator
```

अभिनंदन, आता तुमच्याकडे Raspberry Pi वर चालणारा एक पूर्ण इथेरियम नोड आणि प्रमाणक आहे!

## अधिक तपशील {#more-details}
