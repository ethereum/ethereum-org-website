Solidity मध्ये, [घटना](/developers/docs/smart-contracts/anatomy/#events-and-logs) हे स्मार्ट कॉन्ट्रॅक्ट्सद्वारे पाठवले जाणारे सिग्नल्स असतात. विकेंद्रित ॲप्लिकेशन्स (dapps), किंवा इथेरियम जेसॉन-आरपीसी API शी जोडलेले कोणतेही ॲप्लिकेशन, या घटना ऐकू शकतात आणि त्यानुसार कृती करू शकतात. एखादी घटना अनुक्रमित (indexed) देखील केली जाऊ शकते जेणेकरून नंतर घटनांचा इतिहास शोधता येईल.

## घटना {#events}

इथेरियम ब्लॉकचेनवरील सर्वात सामान्य घटनांपैकी एक म्हणजे `Transfer` घटना, जी जेव्हा कोणी टोकन्सचे हस्तांतरण करते तेव्हा ERC-20 टोकन्सद्वारे पाठवली जाते.

```solidity
event Transfer(address indexed from, address indexed to, uint256 value);
```

घटनेची स्वाक्षरी कॉन्ट्रॅक्ट कोडच्या आत घोषित केली जाते आणि ती emit कीवर्डसह पाठवली जाऊ शकते. उदाहरणार्थ, transfer घटना हस्तांतरण कोणी पाठवले (_from_), कोणाला पाठवले (_to_) आणि किती टोकन्स हस्तांतरित केले गेले (_value_) याची नोंद करते.

चला [तुमचे पहिले स्मार्ट कॉन्ट्रॅक्ट प्रस्थापित करणे](/developers/tutorials/deploying-your-first-smart-contract/) मधील `Counter` स्मार्ट कॉन्ट्रॅक्टकडे परत जाऊया आणि प्रत्येक वेळी मूल्य बदलल्यावर त्याची नोंद करूया. ते असे दिसेल:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract Counter {

    event ValueChanged(uint256 oldValue, uint256 newValue);

    // मोजणीची संख्या ठेवण्यासाठी 'unsigned int' प्रकाराचे सार्वजनिक व्हेरिएबल
    uint256 public count = 0;

    // आपला काउंटर वाढवणारे फंक्शन
    function increment() public {
        count += 1;
        emit ValueChanged(count - 1, count);
    }

    // मोजणीचे मूल्य मिळवण्यासाठी आवश्यक नसलेले गेटर
    function getCount() public view returns (uint256) {
        return count;
    }

}
```

लक्षात घ्या की:

- **ओळ 6**: आपण आपली घटना आणि त्यात काय आहे, जुने मूल्य आणि नवीन मूल्य घोषित करतो.

- **ओळ 14**: जेव्हा आपण आपले count व्हेरिएबल वाढवतो, तेव्हा आपण घटना पाठवतो.

जर आपण आता कॉन्ट्रॅक्ट प्रस्थापित केले आणि increment फंक्शन कॉल केले, तर आपण पाहू की जर तुम्ही logs नावाच्या ॲरेमधील नवीन व्यवहारावर क्लिक केले तर Remix ते स्वयंचलितपणे प्रदर्शित करेल.

तुमच्या स्मार्ट कॉन्ट्रॅक्ट्सचे डीबगिंग करण्यासाठी नोंदी खरोखर उपयुक्त आहेत परंतु जर तुम्ही वेगवेगळ्या लोकांद्वारे वापरले जाणारे ॲप्लिकेशन्स तयार करत असाल तर त्या देखील महत्त्वाच्या आहेत आणि तुमचे स्मार्ट कॉन्ट्रॅक्ट कसे वापरले जाते याचा मागोवा घेण्यासाठी आणि समजून घेण्यासाठी ॲनालिटिक्स करणे सोपे करतात. व्यवहारांद्वारे व्युत्पन्न केलेल्या नोंदी लोकप्रिय ब्लॉक एक्सप्लोरर्समध्ये प्रदर्शित केल्या जातात आणि तुम्ही उदाहरणार्थ विशिष्ट घटना ऐकण्यासाठी आणि त्या घडल्यावर कृती करण्यासाठी साखळीबाह्य स्क्रिप्ट्स तयार करण्यासाठी देखील त्यांचा वापर करू शकता.
