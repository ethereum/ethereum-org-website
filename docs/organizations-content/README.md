# Organizations content pack

First-draft English content for the proposed Organizations navigation hub. The
information architecture, naming, and keyword guardrails are in the
[Organizations hub IA and keyword audit](../organizations-hub-ia-and-keyword-audit.md).
The companion [wireframe index](../organizations-wireframes/README.md) maps a
visual concept to every new route.

```text
│   └── /evidence-and-case-studies

```

All external claims, case studies, and live figures require primary-source and
subject-matter review before publication. ethereum.org should not recommend
vendors, certify compliance, or provide legal, investment, tax, or procurement
advice.
