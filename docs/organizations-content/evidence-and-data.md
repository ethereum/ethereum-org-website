# Evidence for organizational decisions

**Route:** `/enterprise/evidence-and-data`

## Hero

**H1:** Evidence for organizational decisions

Use primary sources, dated technical material, and transparent methodologies to
evaluate a design. An external example can show what has been attempted; it is
not a recommendation or proof that the same design fits another organization.

## What this page indexes

- Ethereum Foundation mandate and protocol documentation
- Ethereum.org technical guides and standards
- Dated case studies with a primary source
- Independent technical assessments and their methodology
- Network data with a maintained source and visible timestamp

## Metadata on every resource

Show publisher, publication date, last review date, resource type, topic, source
URL, and a one-sentence neutral description. Remove stale resources rather than
retaining them to make a list appear complete.

## Data methodology

Definitions vary between sources, especially for ecosystem metrics. Every live
figure needs a source and timestamp; otherwise link to the underlying source.
