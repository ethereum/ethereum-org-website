# Organizations wireframes

Concept wireframes for the proposed Organizations navigation and its Enterprise,
Institutions, and Founders route families. They use ethereum.org's visual
language as a direction, not as final production UI. Final components, copy,
accessibility, and responsive behavior should be designed in the website.

## Shared navigation rules

Every wireframe uses the same primary navigation, with **Organizations** as the
only active item:

`Learn · Use · Build · Participate · Research · Organizations`

Every child page also uses the matching breadcrumb:

- Enterprise: `Home / Organizations / Enterprise / [page title]`
- Institutions: `Home / Organizations / Institutions / [page title]`

The two route hubs may omit a breadcrumb; no child page may omit its immediate
parent.

`/founders` is a first-level Organizations route, so its wireframe omits a
breadcrumb while retaining **Organizations** as the active primary-nav item.
